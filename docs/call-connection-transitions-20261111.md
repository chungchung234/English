# 통화 연결·종료 경험

2026-11-11 KST. 기존 화면 디자인을 유지하면서 요청한 전화 연결·종료 감각을 추가한다.

- 연결: 클릭 직후 부드러운 두 음을 낮은 볼륨으로 재생하고, 연결 상태에 작은 점멸 표시를 둔다. 별도 최소 대기 시간을 넣지 않는다. 실제 RTC 연결과 데이터 채널 준비가 모두 확인되면 연결음을 즉시 정리하고 마이크 전송과 첫 응답을 시작한다.
- 종료: 마이크, 상대 음성 재생, 통화 타이머, 캐릭터 움직임과 조작을 즉시 멈춘다. 약 0.33초의 짧은 하행 종료음을 재생하고 약 0.6초 동안 종료된 화면을 보여준 뒤 대화문으로 이동한다.
- 저장: 마지막 발화 전사·저장은 종료 연출과 병렬이다. 기존 최종 전사 대기에 0.6초를 더하지 않으며, 늦은 발화·부분 실패·저장 확인의 구분을 유지한다.
- 실패: 연결 실패·종료·페이지 이탈 시 음원과 타이머를 정리한다. 오디오 사용이 차단돼도 연결과 저장은 진행한다. 움직임 줄이기 환경에서는 연결 점멸을 끈다.
- 범위: 시간·음높이·음량은 이 요청을 위한 제품 설정값이다. 학습 효과나 보편적인 최적 대기 시간으로 해석하지 않는다. 모델·페르소나·기억·DB 정책은 변경하지 않는다.

검증은 실제 브라우저의 WebAudio, 마이크 트랙, WebGL 렌더 횟수와 IndexedDB를 사용하고, 인증·WebRTC 연결 및 공급자/서버 응답은 fixture로 통제한다. 실제 승인 계정의 음성 통화나 사용자 주관의 음질 평가를 대신하지 않는다. 최종 배포 커밋과 CI 결과는 이 변경의 PR에 기록한다.
