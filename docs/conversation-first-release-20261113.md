# 자연 대화 우선·사후 학습 분리

작업일: 2026-11-13 KST. 기준 소스: `3b24f5a`.
제품 목적의 상위 기준은 [전화 영어의 제품 목적](research/phone-english-purpose.md)이다.

## 바로잡은 원인과 동작

이전 목적·페르소나·학습 설계 문서는 교육 연구의 산출·교정·목표 수행을 통화의 상위 목표로 옮겼다. 실제 공통 지침도 학습자 지원을 첫 역할로 두었고, 저장한 복습 표현·교정·학습 목표·AI의 다음 상황 제안이 실시간 맥락으로 들어갔다. 관련 논문을 반증한 것이 아니라 제품 목표와 연구 적용 범위를 정정했다. 문서별 근거와 코드 연결은 상위 목적 문서의 추적 표에 기록했다.

- 통화의 역할은 캐릭터와 함께 이야기하기다. Mia의 세심한 반응, Alex의 자기 관점, Juno의 가벼운 연상이 실제 말투로 드러나도록 한다. 문장·질문 수나 필수 시작 행동을 부여하지 않는다.
- 실시간 맥락은 검증된 프로필, 날짜와 사용자 인용을 가진 대화 기억, 현재 통화의 대화 요약만 허용한다. 교정·연습·목표·옛 학습 평가 요약·미래 수업 지시는 전달하지 않는다. 사용자가 실제로 말한 원문은 단어에 따라 삭제하거나 바꾸지 않는다.
- 시작 자료는 선택적 배경이다. 과거 질문과 지금 발화를 구분하고, 이전 인사를 그대로 수행하는 시작 행동·전략 필드는 제거했다. 저장한 복습 계획이 새 통화 주제로 자동 변환되지 않는다.
- 통화 중간 요약은 대화 연속성 전용 `summary` 계약을 쓴다. 예전 교정·다음 상황이 있는 캐시와 새 버전·요청 키를 분리했다. 출처·기억 수정·제외·계정/캐릭터 소유권·qualified 발화 범위 검증은 유지한다.
- 복습 선택은 통화 후 원문 근거와 관찰 기록에 남는다. 사용 표현 관찰을 위한 비공개 준비는 최대 1.8초의 선택적 처리이며, 그 실패나 사용하지 않는 학습 목표의 변경이 통화를 막지 않는다. 기억 제외·잊기 상태는 계속 검증한다.
- “이걸 영어로 뭐라고 해?” 같은 명시 요청에는 바로 도움을 준다. 통화 후 학습 노트·선택 복습·사용자 원문/근거 연결은 보존한다.

## 검증의 구분

로컬 기능·브라우저 검사는 실제 코드·SQL·Chromium을 사용하되 인증·provider·WebRTC 전송은 합성 fixture다. 저장 ACK, 원문, 계정 격리, 사후 근거와 자연 통화 주제의 분리를 확인한다. 이 결과를 대화 자연스러움이나 실제 마이크 음향 검증으로 보고하지 않는다.

별도 실제 provider 검사는 기존 서버 자격 증명을 서버 안에서만 사용하고, 고정 합성 발화만 전달한다. 실계정·대화 DB·승인 목록은 쓰지 않는다. 임시 함수는 요청 상한·난수 인증·유효시간을 두고 제거 및 목록 부재까지 확인한다. WS의 실제 오디오 생성/전사와 요청 계약을 확인하지만 휴대폰 재생·AEC·소음 차단 체감을 입증하지 않는다.

첫 후보의 15개 응답은 모두 정상 완료했고 대화 전용 요약 1회도 계약을 충족했다. 그러나 시작 3개 모두 자기소개·도우미 설명을 했고, 일상 공유에 요청 없는 조언이 붙었다. 따라서 이를 품질 개선 성공으로 채택하지 않았다. 중복된 지침을 압축하고, AI 신원·사실 경계와 캐릭터의 실제 발화 말투를 분리해 재검증한다. 이는 출력에 근거한 개선 가설이며, 금지 목록이나 짧은 인사 상한으로 대체하지 않는다.

같은 시작·첫 응답의 축소 재검사 6개에서도 도우미식 인사가 남았다. 이후 시작 6개를 추가로 비교했다. 3개는 mini 모델에서 이전 인사 자료만 제거했고, 3개는 같은 자료·지침으로 standard 모델을 명시했다. provider가 실제 선택한 모델도 확인했다. 두 조건 모두 일반적인 도우미 안내가 남아, 이전 인사 전달만이 원인이라고 단정하거나 상위 모델 교체를 해결책으로 채택하지 않았다. 소표본의 시작 장면 비교이며 모델 전반의 우열을 증명하지 않는다. 운영 모델은 그대로다.

## 기능·화면 검증

- `npm run check` 및 전체 단위·SQL 검사 **451개 통과**, 실패·skip 없음. 배포 패키지의 새 전이 의존 모듈 포함 검사도 통과했다.
- 기억 평가·합성 학습 평가, post-call 및 enhancement 브라우저 검사를 통과했다. 저장한 복습 계획이 있어도 새 session의 scenario가 자연 대화이며, `#next-plan`이 숨겨지는 것을 실제 SQL/화면에서 확인했다.
- qualified-turn 브라우저 5개 사례, live-smoke 관찰기 15개 사례를 통과했다. 이는 실제 모델의 말투나 휴대폰 음향 효과를 평가하지 않는다.
- 복습 완료·선택적 주간 복습·계획 저장 후 연락처 화면을 390px/16px 글자와 320px/20px 글자에서 실제로 열어 확인했다. 버튼 잘림·가로 넘침이 없고 주간 복습의 마지막 버튼도 하단 탐색막대 위로 스크롤해 접근할 수 있다. [로컬 기록](design/conversation-first-20261113/local-ui-inspection.json).
- 독립 코드 검토에서 live 자료 허용 범위·checkpoint 격리·개인정보/출처 검증·선택 학습 준비 경계에 남은 blocking을 찾지 못했다. 실제 생성 품질 판정과는 별개다.

합성 provider의 프로토콜 기록은 [첫 후보](design/conversation-first-20261113/candidate1-protocol.json), [축소 재검사](design/conversation-first-20261113/candidate2-gate-protocol.json), [인사/모델 비교](design/conversation-first-20261113/model-history-diagnostic.json)에 있다. 완료 수를 품질 성공 수로 바꾸지 않는다.

## 최종 생성 결과와 남은 한계

최종 소스에서 동일한 세 캐릭터·현재 사용자 발화에 날짜와 사용자 인용이 있는 과거 대화 자료를 더해, 시작 1회와 실제 사용자 입력 후 응답 4회씩 **15응답**을 연속 검사했다. 별도 checkpoint 생성은 반복하지 않았으며 Mia의 중간 재주입 요약은 작성된 합성 fixture다. 총 15응답 모두 `completed`, provider/parse/unexpected-response 오류 0, 사용자 item ACK와 실제 assistant/user reference 순서가 맞았다. source 지문·전달 지침·임시 함수 삭제/목록 부재도 확인했다. [프로토콜 기록](design/conversation-first-20261113/continuity-protocol.json).

작업자가 합성 생성 전사를 읽은 결과, 이해 가능한 문법 실수를 먼저 교정하지 않았고, 한국어 표현 질문에는 영어 표현을 바로 주었다. 도움 거절 후 조리 조언을 추가하지 않았으며 새 화제로 전환했다. 그러나 시작 3개 모두 대화 메뉴나 도우미 안내로 돌아갔고, 과장된 칭찬·공감과 반복적인 서비스형 마무리도 남았다. 이력 전달과 기억 receipt는 실제 회상을 사용했다는 증거가 아니다. 친근함·캐릭터 차별화·반복 감소의 품질 기준은 **아직 충족하지 못했다**. 결과를 편집한 예시로 대체하지 않았고, 프롬프트나 고가 모델만으로 해결됐다고 보고하지 않는다.

이번 변경의 검증된 범위는 제품 목적 정정, live와 사후 학습의 데이터/역할 분리, 개인정보·원문·후속 학습 기능 보존이다. 자연스러운 친교 대화의 완성이나 실제 휴대폰의 소음·에코 효과를 검증한 릴리스는 아니다. 다음 품질 작업은 캐릭터의 지속적 취향과 대화별 관심 문맥이 실제 응답에 반영되는지, 여러 통화에서 상투적인 시작·칭찬·진행자 말투가 줄어드는지를 따로 평가해야 한다. 인사 길이 상한이나 필수 질문/행동을 추가해 합격으로 바꾸지 않는다.
