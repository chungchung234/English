## 바로잡은 원인과 동작

이전 목적·페르소나·학습 설계 문서는 교육 연구의 산출·교정·목표 수행을 통화의 상위 목표로 옮겼다. 실제 공통 지침도 학습자 지원을 첫 역할로 두었고, 저장한 복습 표현·교정·학습 목표·AI의 다음 상황 제안이 실시간 맥락으로 들어갔다. 관련 논문을 반증한 것이 아니라 제품 목표와 연구 적용 범위를 정정했다. 문서별 근거와 코드 연결은 상위 목적 문서의 추적 표에 기록했다.

- 통화의 역할은 캐릭터와 함께 이야기하기다. Mia의 세심한 반응, Alex의 자기 관점, Juno의 가벼운 연상이 실제 말투로 드러나도록 한다. 문장·질문 수나 필수 시작 행동을 부여하지 않는다.
- 실시간 맥락은 검증된 프로필, 날짜와 사용자 인용을 가진 대화 기억, 현재 통화의 대화 요약만 허용한다. 교정·연습·목표·옛 학습 평가 요약·미래 수업 지시는 전달하지 않는다. 사용자가 실제로 말한 원문은 단어에 따라 삭제하거나 바꾸지 않는다.
- 시작 자료는 선택적 배경이다. 과거 질문과 지금 발화를 구분하고, 이전 인사를 그대로 수행하는 시작 행동·전략 필드는 제거했다. 저장한 복습 계획이 새 통화 주제로 자동 변환되지 않는다.
- 통화 중간 요약은 대화 연속성 전용 `summary` 계약을 쓴다. 예전 교정·다음 상황이 있는 캐시와 새 버전·요청 키를 분리했다. 출처·기억 수정·제외·계정/캐릭터 소유권·qualified 발화 범위 검증은 유지한다.
- 복습 선택은 통화 후 원문 근거와 관찰 기록에 남는다. 사용 표현 관찰을 위한 비공개 준비는 최대 1.8초의 선택적 처리이며, 그 실패나 사용하지 않는 학습 목표의 변경이 통화를 막지 않는다. 기억 제외·잊기 상태는 계속 검증한다.
- “이걸 영어로 뭐라고 해?” 같은 명시 요청에는 바로 도움을 준다. 통화 후 학습 노트·선택 복습·사용자 원문/근거 연결은 보존한다.

## 검증의 구분

로컬 기능·브라우저 검사는 실제 코드·SQL·Chromium을 사용하되 인증·provider·WebRTC 전송은 합성 fixture다. 저장 ACK, 원문, 계정 격리, 사후 근거와 자연 통화 주제의 분리를 확인한다. 이 결과를 대화 자연스러움이나 실제 마이크 음향 검증으로 보고하지 않는다.

별도 실제 provider 검사는 기존 서버 자격 증명을 서버 안에서만 사용하고, 고정 합성 발화만 전달한다. 실계정·대화 DB·승인 목록은 쓰지 않는다. 임시 함수는 요청 상한·난수 인증·유효시간을 두고 제거 및 목록 부재까지 확인한다. WS의 실제 오디오 생성/전사와 요청 계약을 확인하지만 휴대폰 재생·AEC·소음 차단 체감을 입증하지 않는다.

첫 후보의 15개 응답은 모두 정상 완료했고 대화 전용 요약 1회도 계약을 충족했다. 그러나 시작 3개 모두 자기소개·도우미 설명을 했고, 일상 공유에 요청 없는 조언이 붙었다. 따라서 이를 품질 개선 성공으로 채택하지 않았다. 중복된 지침을 압축하고, AI 신원·사실 경계와 캐릭터의 실제 발화 말투를 분리해 재검증한다. 이는 출력에 근거한 개선 가설이며, 금지 목록이나 짧은 인사 상한으로 대체하지 않는다.

최종 검사·공개 배포 증거는 배포 완료 후 이 문서에 별도로 기록한다.
