# 로그인 전환

기존 화이트·브랜드 블루·네이비와 작은 글래스 상태 표시를 사용한다. 일반 로그인 안내문 대신 중앙 로고와 짧은 상태 문구로 구성했다. 기존 로고를 재사용하며 로그인 전에 캐릭터 이미지나 새로운 이미지 파일을 요청하지 않는다.

- [변경 전](before.png), [390×844](mobile.png), [320×568 / 동작 줄이기](compact.png)
- 승인 확인 전에는 홈과 비공개 기록을 노출하지 않는다. 기존 병렬 계정 확인과 제공자 설정 비차단 흐름은 유지한다.
- 진입은 4px/180ms의 작은 등장, 승인 후에는 180ms 크로스페이드로 홈에 이어진다. 최소 대기 시간이나 가짜 진행률은 없다. 홈은 승인 즉시 표시·활성화되며 사라지는 화면은 입력을 가로막지 않는다.
- 전체 홈을 이동시키지 않고 불투명도만 바꾸므로 고정 하단 내비게이션의 위치는 유지한다. 취소·오류·로그아웃 때 기존 애니메이션을 취소하고 지연된 완료 콜백이 새 화면을 숨기지 않도록 구분한다.
- 동작 줄이기에서는 등장·크로스페이드·상태 모션을 생략한다. 텍스트 대비는 제목17.26:1, 상태5.73:1(화이트 위 합성 표면 기준), 하단 문구5.93:1이다.

스크린샷과 브라우저 검증은 계정·승인 응답을 지연시킨 fixture를 사용했다. 실제 사용자 로그인이나 운영 계정 기록을 캡처하지 않았다. 로그인/승인/홈 전환, 느린 제공자 조회, 입력 비차단, 동작 줄이기를 브라우저에서 확인한다.
