# 브라우저 fixture 서버 시작 복구

CI 43589882831은 앱 검증 전에 qualified fixture 서버가 exit 1로 끝나 중단됐다.
당시 자식 stderr는 표시되지 않아 정확한 과거 errno를 복구할 수 없다.

고정 49446·49447 포트를 각각 점유하면 기존 서버에서 같은 exit 1과 EADDRINUSE가
재현된다. 두 포트를 동시에 점유한 채 수정한 qualified·authored 전체 검사를
차례로 실행했고 모두 통과했다. 실제 새 포트는 42127·40331이었다. 점유한 기존
포트에는 요청이 없었으며 자식·리스너 종료와 포트 재사용까지 확인했다.

테스트는 OS가 배정한 포트를 읽고 그 주소로 앱·Worklet·CSP를 빌드한다. 서버
준비 신호·포트 범위를 확인하고 stdout/stderr를 제한된 크기로 보존한다.
실패·브라우저 시작 오류 때도 서버 종료를 기다린다. 동작 assertion과 기존
브라우저 대기 시간은 줄이거나 느슨하게 바꾸지 않았다. 제품 코드는 변경하지 않는다.

이 재현은 포트 충돌 메커니즘과 수정의 유효성을 확인한다. 과거 CI의 정확한
포트 점유 주체를 입증한 결과는 아니다. 실제 모델·사용자 데이터 접근은 없다.
