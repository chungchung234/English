# 통화 홈 · 글래스 조작부

2026-11-10. 사용자가 선택한 중앙 구체 시안의 구성에 구분선 제거·공통 글래스 조작부를 반영했다. 이후 피드백인 **플랫한 녹색 발신 버튼**이 이미지의 광택 표현보다 우선한다.

## 결정

- 상단: Alex/Juno/Mia 이름으로 선택. 이름 반복, 검색, 연락처 제목, 사람 모양 아이콘 제거.
- 중앙: 기존 승인 AI 구체와 성격 한 줄. 선택은 통화를 시작하지 않는다.
- 조작부: 상대 선택·설정·하단 메뉴에 같은 글래스 토큰. 선택 바 안에는 세로 구분선이 없다. 선택 캡슐은 이동하되 동작 줄이기를 존중한다.
- 발신: 그림자·그라데이션·입체 하이라이트 없는 단색 녹색 버튼. 실제 앱 검수에서 `boxShadow: none` 확인.
- 기능: 선택 상대를 재접속 후 유지. 기억 관리는 내 계정과 최근 통화에서 접근. 통화 실패 후 선택한 상대의 홈으로 복귀한다.
- 시간: 통화 전 제한 문구를 나열하지 않는다. 연결 후 경과 시간, 마지막 1분에 남은 시간을 표시하며 기존 20분 종료·저장 동작을 유지한다.

이미지는 실제 앱을 Chromium에서 렌더링하고 API와 인증을 브라우저의 합성 응답으로만 대체한 화면이다. 실제 사용자 계정·기록에 접근하지 않았다. 배포용 CSP와 이미지 하위 경로도 별도 브라우저 검사에서 확인했다.

## 검증

- `npm test`: 82/82 통과.
- `npm run check`, `npm run test:presence`, `npm run test:browser`: 통과.
- 상대 선택과 키보드 이동이 통화를 만들지 않음, 새로고침 후 선택 유지, 내 계정의 기억 관리, 기존 저장·복습·실패 재시도·다시 걸기 검증.
- 390×844 및 320×568의 가로 넘침 없음. 작은 화면에서도 통화 버튼이 하단 메뉴 위에 남는다. 선택 버튼 누름 영역 44px, 실행 오류 0건.
- 오디오 반응은 실제 생성한 브라우저 오디오 트랙으로 검사했다. AI 제공자 통화와 OAuth 제공자 응답은 모의이며 실계정 통화 성공을 주장하지 않는다.

웹의 반투명·블러·경계빛 표현이며 애플 네이티브 Liquid Glass API를 사용하는 앱은 아니다. 실제 iPhone Safari의 재질·마이크·백그라운드 동작은 별도 실기기 확인 범위다.
