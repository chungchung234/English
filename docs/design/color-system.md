# 시시콜콜 컬러 시스템

로고의 선명한 블루와 깊은 네이비를 기준으로 한 라이트 테마. 기본 화면은 차분한 화이트로 유지하고 색은 주요 행동, 선택, 상태를 구분하는 데 사용한다.

| 역할 | 색상 | 용도 |
|---|---|---|
| Brand | #3038EE | 주요 행동, 포커스 |
| Brand strong | #252BB5 | 선택 텍스트, 개선 표현 |
| Text | #081744 | 제목, 본문 |
| Secondary text | #59647C | 설명, 날짜, 비활성 탭 |
| Canvas | #FFFFFF | 읽기 영역 |
| Soft surface | #F3F5FC | 입력, 보조 컨트롤 |
| Selection | #E9ECFF | 현재 탭, 선택된 대화 상대 |
| Border | #E2E6F1 | 구분선, 입력 경계 |
| Success | #187348 | 전화 걸기 |
| Warning | #916008 | 전송 대기 표시 |
| Danger | #D9323C | 통화 종료 |

CSS 토큰은 web/style.css의 :root에서 관리한다. 발신은 녹색, 종료는 빨간색, 선택과 기본 행동은 브랜드 블루를 사용한다. 모바일 전화 UI의 정보 구조·크기·최신 검증은 [검증 기록](phone-ui-qa.md)에 정리했다.

2026-11-10 통화 홈 수정: 상단 상대 선택·설정 버튼·하단 메뉴는 공통 글래스 표면/경계/그림자 토큰을 사용한다. 상단 선택 바에는 내부 구분선이 없고 선택 캡슐이 이동한다. 발신 버튼은 최종 사용자 피드백에 따라 **단색 녹색, 그림자·하이라이트 없는 플랫 버튼**을 유지한다. 구체에 유리 카드나 장식을 덧씌우지 않는다. [최신 화면과 검증](call-glass/README.md).

## 적용한 스킬

- [OpenAI Liquid Glass](../../.agents/skills/liquid-glass/SKILL.md): SwiftUI/macOS 전용 API를 웹에 직접 쓰지 않고, 유리 효과를 플로팅 내비게이션과 컨트롤에 제한하고 의미 있는 색상만 사용하는 원칙을 적용했다. 웹에서는 backdrop-filter, 반투명 표면, 하이라이트 경계로 표현한다. 네이티브 Liquid Glass 렌더링과 동일하지 않다.
- [Impeccable colorize](../../.agents/skills/impeccable-colorize/SKILL.md): 브랜드 색 보존, 역할별 토큰, 행동/선택 위계, 색 대비 검증 지침. [원문](https://github.com/pbakaus/impeccable/blob/main/skill/reference/colorize.md).

## 검증

모바일 브라우저의 연락처·상세·통화·복습·기록 화면 캡처 및 기존 기능 회귀 검사. 주요 명시 색상 대비: 본문/화이트 17.26:1, 보조 텍스트/화이트 5.93:1, 보조 텍스트/보조 표면 5.45:1, 흰색/발신 버튼 5.86:1, 선택 텍스트/선택 배경 8.56:1, 흰색/종료 버튼 4.70:1. 통화 화면의 보조 텍스트/그라데이션 최밝은 색은 7.99:1, 저장 상태는 6.35:1이다. 반투명 표면의 실시간 배경 전체에 대한 수학적 보장은 아니므로 감소된 투명도·고대비 환경 및 backdrop-filter 미지원 환경에는 불투명 대체 표면을 제공한다. 선택은 aria-current, aria-pressed와 위치·배경·굵기로 함께 나타낸다.

## 승인된 AI 캐릭터와 음성 반응

최종 기준은 [사용자가 승인한 캐릭터 시안](approved-characters/reference.png)이다. 색만 바꾸는 구체를 폐기하고 시안에서 생성한 투명 이미지 세 장을 사용한다.

- Alex: 블루·인디고, 균형 잡힌 구형, 한 방향으로 정돈된 내부 흐름.
- Mia: 라벤더·따뜻한 빛, 아래가 넓고 부드러운 윤곽, 감싸는 물결과 긴 여운.
- Juno: 아쿠아·블루, 부드러운 비대칭 윤곽, 유연한 방향 전환.

원본 자산은 `web/assets/ai-alex.png`, `ai-mia.png`, `ai-juno.png`이며, 배포에는 RGBA 픽셀이 동일한 `.webp` 파일을 사용한다. 얼굴·이모지·외부 장식은 없다. 색·질감·윤곽은 이미지에 보존하고 WebGL에서는 이미지의 내부 좌표와 윤곽을 작게 변형한다. 고정된 띠가 돌거나 전체 구체가 화면을 떠다니는 움직임을 사용하지 않는다. 연락처·상세·통화 화면에 같은 이미지를 사용한다.

### 움직임과 신호

상태는 대기/연결/듣기/생각/말하기/오류로 나누되 내부 상태 가중치를 이어서 전환한다. 움직임의 시간을 속도에 맞춰 누적하므로 상태가 바뀌어도 흐름이 갑자기 뛰지 않는다. 말하기 진입 때 일률적으로 팽창하는 효과는 없다. 내부 흐름과 작은 윤곽 반응은 실제 입력/출력 RMS의 강약을 따르며, 무음에 가짜 발화 신호를 넣지 않는다. Mia는 감쇠를 길게, Juno는 더 탄력 있게, Alex는 그 사이의 안정적인 리듬으로 설정했다.

`output_audio_buffer.started/stopped/cleared`로 AI 발화 상태를 구분하고 사용자 발화와 응답 생성 이벤트로 듣기/생각을 전환한다. 입력/출력 트랙은 별도 분석기로 읽되 중복 재생하거나 음성을 저장하지 않는다. 종료/실패 시 AudioContext와 분석 연결을 해제하며 호출 트랙 수명은 기존 통화 코드가 관리한다.

동작 줄이기 설정에서는 동일 이미지의 정지 상태를 유지한다. WebGL 미지원·컨텍스트 유실 때에는 같은 원본 이미지에 작은 CSS 호흡·기울기만 적용하며, 이 대체 움직임도 동작 줄이기 설정에서는 멈춘다. 가려진 화면과 백그라운드 탭에서는 그리지 않는다. 512px 공유 비트맵을 사용하고, 각 렌더링 표면에는 현재 캐릭터의 텍스처 한 장만 업로드한다.

### 근거와 검증

- [Google Gemini의 시각 디자인 해설](https://design.google/library/gemini-ai-visual-design): 밀도/확산, 내부 활동, 의도 있는 모션.
- [VoiceOrbs 상태 전환](https://github.com/amunozdev/voiceorbs/blob/main/src/registry/lib/orb-state.ts): 연속된 상태 가중치와 활성/진정의 다른 전환 속도.
- [Murmur 상태 설계](https://github.com/krispuckett/murmur/blob/main/Sources/Murmur/MurmurState.swift): 같은 존재의 상태 변화, 위상이 뛰지 않는 시간 누적.

외부 소스의 시각 자산이나 SDK는 포함하지 않았다. 캐릭터 자산은 승인 시안을 참조해 생성했으며 렌더러는 앱에서 작성했다. 감정 분석 기능을 도입한 것은 아니다.

`npm run test:presence`는 실제 이미지 텍스처 렌더링, 캐릭터별 구분, 정지 모션, 실제 오디오 트랙으로 인한 픽셀 변화, 분석 연결/해제, 트랙 수명 유지, WebGL 대체 표시를 검사한다. `npm run test:browser`는 통화 상태 이벤트, 상대 선택, 기존 저장·통화 흐름 및 hashed CSP의 배포용 HTML을 검사한다. 업스트림 AI 통화는 시뮬레이션한다.

[실제 렌더러 모션 영상](approved-characters/motion.mp4)은 상태와 강약을 비교하기 위해 합성한 오디오 신호를 사용하며, 실제 AI 대화 녹화가 아니다.

### 단계별 외곽 반응 개선

사용자 피드백에 따라 내부 흐름에 가려졌던 외곽 변화를 분명하게 했다. 대기는 중심 주변에서 작은 호흡·기울기·윤곽 흐름을 이어가고, 듣기는 여기에 입력 RMS에 따른 세로 반응이 더해진다. 생각은 약간 수렴하며 내부 흐름이 모이고, 말하기는 출력 RMS에 따라 부피·기울기·윤곽이 유기적으로 변한다. 모든 캐릭터가 떠다니는 동작이나 말하기 상태만으로 가짜 발화 진폭을 넣는 방식은 사용하지 않는다.

[단계별 비교 영상](approved-characters/stage-comparison.mp4)은 같은 캐릭터의 네 상태를 동시에 보여준다. 입력·출력에 같은 합성 강약 패턴을 주고, 대기·생각에는 신호를 주지 않는다. `test:presence`는 음성에 따른 RGB 변화뿐 아니라 알파 채널 변화도 확인해 실제 외곽이 달라지는지 검사한다. 내부 텍스처 변형은 외곽에서 감쇠시켜 이중 윤곽처럼 보이는 현상을 막는다.

2026-11-10 사용자 요청으로 무음 상태의 움직임을 보강했다. 음성 강약과 독립된 연속 시계로 약10~14초 주기의 작은 호흡(가로1.8%, 세로2.8%), 중심 주변 이동과 기울기를 준다. 상태 전환 때 호흡 위상을 재시작하지 않으며 프레임 상한과 백그라운드 정지는 유지한다. 무음의 기본 움직임을 발화 신호로 사용하지 않으며 실제 음성 RMS는 별도 반응으로 더해진다. 세 캐릭터 모두 입력 음성 없이 알파 윤곽이 변하는지를 실제 WebGL 픽셀로 검사한다.

상대 탭 선택 시 선택 렌즈와 캐릭터가 같은280ms 곡선으로 전환한다. 오른쪽 탭은 새 캐릭터가 오른쪽에서 들어오고 이전 캐릭터는 왼쪽으로 빠지며, 반대 선택은 역방향이다. 이전 WebGL 프레임을 즉시 복사해 흰 화면 없이 넘기고 전환 종료·연속 선택·탭 이탈 때 복사 표면을 정리한다. 동작 줄이기 설정에서는 슬라이드 없이 바로 바뀐다.
