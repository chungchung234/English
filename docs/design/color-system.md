# 시시콜콜 컬러 시스템

로고의 선명한 블루와 깊은 네이비를 기준으로 한 라이트 테마. 기본 화면은 차분한 화이트로 유지하고 색은 주요 행동, 선택, 상태를 구분하는 데 사용한다.

| 역할 | 색상 | 용도 |
|---|---|---|
| Brand | #3038EE | 주요 행동, 포커스 |
| Brand strong | #252BB5 | 선택 텍스트, 개선 표현 |
| Text | #081744 | 제목, 본문 |
| Secondary text | #59647C | 설명, 날짜, 비활성 탭 |
| Canvas | #FFFFFF | 읽기 영역 |
| Soft surface | #F3F5FC | 입력, 보조 컨트롤 |
| Selection | #E9ECFF | 현재 탭, 선택된 대화 상대 |
| Border | #E2E6F1 | 구분선, 입력 경계 |
| Success | #187348 | 전화 걸기 |
| Warning | #916008 | 전송 대기 표시 |
| Danger | #D9323C | 통화 종료 |

CSS 토큰은 web/style.css의 :root에서 관리한다. 발신은 녹색, 종료는 빨간색, 선택과 기본 행동은 브랜드 블루를 사용한다. 모바일 전화 UI의 정보 구조·크기·최신 검증은 검증 기록에 정리했다.

2026-11-10 통화 홈 수정: 상단 상대 선택·설정 버튼·하단 메뉴는 공통 글래스 표면/경계/그림자 토큰을 사용한다. 상단 선택 바에는 내부 구분선이 없고 선택 캡슐이 이동한다. 발신 버튼은 최종 사용자 피드백에 따라 **단색 녹색, 그림자·하이라이트 없는 플랫 버튼**을 유지한다. 캐릭터에 유리 카드나 장식을 덧씌우지 않는다. 최신 화면과 검증.

## 적용한 스킬

- [OpenAI Liquid Glass](../../.agents/skills/liquid-glass/SKILL.md): SwiftUI/macOS 전용 API를 웹에 직접 쓰지 않고, 유리 효과를 플로팅 내비게이션과 컨트롤에 제한하고 의미 있는 색상만 사용하는 원칙을 적용했다. 웹에서는 backdrop-filter, 반투명 표면, 하이라이트 경계로 표현한다. 네이티브 Liquid Glass 렌더링과 동일하지 않다.
- [Impeccable colorize](../../.agents/skills/impeccable-colorize/SKILL.md): 브랜드 색 보존, 역할별 토큰, 행동/선택 위계, 색 대비 검증 지침. [원문](https://github.com/pbakaus/impeccable/blob/main/skill/reference/colorize.md).

## 검증

모바일 브라우저의 연락처·상세·통화·복습·기록 화면 캡처 및 기존 기능 회귀 검사. 주요 명시 색상 대비: 본문/화이트 17.26:1, 보조 텍스트/화이트 5.93:1, 보조 텍스트/보조 표면 5.45:1, 흰색/발신 버튼 5.86:1, 선택 텍스트/선택 배경 8.56:1, 흰색/종료 버튼 4.70:1. 통화 화면의 보조 텍스트/그라데이션 최밝은 색은 7.99:1, 저장 상태는 6.35:1이다. 반투명 표면의 실시간 배경 전체에 대한 수학적 보장은 아니므로 감소된 투명도·고대비 환경 및 backdrop-filter 미지원 환경에는 불투명 대체 표면을 제공한다. 선택은 aria-current, aria-pressed와 위치·배경·굵기로 함께 나타낸다.

## 승인된 캐릭터 · 2026-11-17

[최신 승인 시안](approved-characters/reference.png)을 기준으로 기존 빛 구체를 교체했다. 단색 몸체와 흰 캡슐 눈을 공유하고 실루엣으로 구분한다. 블루·말풍선 로고를 그대로 캐릭터로 만드는 안은 폐기했다.

| 캐릭터 | 정확한 몸체 색 | 형태 | 반응 성격 |
|---|---|---|---|
| Alex | #4856A6 | 기울어진 둥근 사각형 | 안정적인 중간 반응 |
| Mia | #D86178 | 세 갈래 둥근 구름 | 부드럽고 긴 여운 |
| Juno | #4B87DB | 비대칭 둥근 삼각형 | 조금 빠르고 탄력 있는 반응 |

원본은 `web/assets/ai-{alex,mia,juno}.png`, 배포는 동일 RGBA의 lossless WebP다. Image Gen으로 생성한 실제 몸체·눈 자산을 사용한다. 런타임에서는 가장 큰 연결 실루엣과 안티앨리어싱 테두리를 보존해 떨어진 알파 잡음을 제거하고, 몸체를 승인 색으로 정규화한다. 같은 정리된 이미지가 WebGL·정지 대체 이미지·스와이프 미리보기에 쓰인다. 눈은 이미지의 흰 영역을 검출하고 실제 눈 텍스처를 변형하며 코드로 새 모양을 그리지 않는다.

## 모션 문법

눈은 주의의 방향, 몸체는 실제 음성의 리듬을 전달한다. `web/character-motion.js`가 모든 캐릭터에 같은 문법을 적용하며 비율·응답 강도·감쇠 속도만 구분한다. 웃는 입·표정 장식·이해를 단정하는 반복 끄덕임·사용자 감정 추정은 없다.

| 상태 | 근거 | 눈 | 몸체 |
|---|---|---|---|
| 홈 대기 | 통화 전 | 간헐적 깜빡임 | 중심을 유지하는 작은 호흡 |
| 연결/재연결 | 기존 연결 생명주기 | 천천히 모였다 돌아옴 | 고정 중심, 점프 없음 |
| 듣기 | 실제 사용자 차례 | 정면 시선 | 작은 기울기와 입력 RMS 반응 |
| 답변 준비 | 응답 생성 상태 | 위로 시선 이동, 눈 길이 차이 | 약간 수렴 |
| 말하기 | 실제 출력 재생 + RMS | 자연스러운 눈 길이 반응 | 음량에 따른 눌림·늘어남, 근사 면적 유지 |
| 끼어들기 | 출력 중단/사용자 차례 복귀 | 빠르게 정면 복귀 | 출력 반응을 즉시 끊고 약100ms대로 진정 |
| 마이크 꺼짐 | 실제 음소거 상태 | 듣기에서 안정된 반쯤 열린 눈 | 입력 반응 정지, AI의 실제 출력 반응은 유지 |
| 오류 | 기존 오류 상태 | 안정된 짧은 눈 | 움직임 정착, 복구 안내 문구 병행 |
| 종료 | 기존 ending 단계 | 중립 자세 | 중립 프레임을 그린 뒤 정지 |

상태 보간은 일반적으로180~280ms, 끼어들기는 약100~150ms를 목표로 한 초기 튜닝이다. 음성 자체는 입력·출력 트랙을 각각 분석하고 무음에 가짜 발화 진폭을 넣지 않는다. 모션은 실제 이해·분석 완료나 감정을 증명하지 않는다. 중요한 연결·저장·오류 정보는 기존 문구와 컨트롤에서 함께 전달한다.

동작 줄이기에서는 상태·음량과 무관하게 동일한 정지 캐릭터를 유지한다. WebGL 미지원/컨텍스트 유실 시에도 같은 색·실루엣의 정지 이미지와 상태 문구를 사용한다. 백그라운드와 화면 밖 렌더링은 중단하고 종료 시 분석 연결과 AudioContext를 해제한다. 시각화는 통화 트랙을 중단하거나 중복 재생하지 않는다.

## 기존 화면과 상호작용

로고·글래스 상대 선택 바·중앙 캐릭터 자리·플랫 녹색 통화 버튼·통화/최근 통화/복습 메뉴를 유지한다. 상대 탭과 화면 스와이프는 기존280ms 곡선·방향·페더 마스크를 그대로 사용하며 동작 줄이기에서는 즉시 전환한다. 세로 스크롤·확대·버튼 클릭 억제 경계를 보존한다.

## 근거와 검증 범위

- [사용자 제공 Bot Animation States](https://recent.design/i/f4gsm71-bot-animation-states): 단색 실루엣과 흰 캡슐 눈의 표현 방식. 제공된 포스터의 시각 원칙을 참고해 새 자산을 생성했다. 원본 동영상의 정확한 타이밍을 역공학했다고 주장하지 않는다.
- [Google 대화 설계](https://developers.google.com/assistant/conversation-design/learn-about-conversation): 대화 차례와 협력적인 피드백. 구체적인 상태·움직임·수치는 이 제품을 위한 설계 제안이다.
- [Duolingo 캐릭터 설계](https://blog.duolingo.com/building-character/): 가족 간 공유 형태·표현 규칙.
- [W3C 동작 줄이기](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions): 불필요한 움직임을 끄는 사용자 설정 존중.

기준 커밋은 원격 기본 브랜치 `884d794`. 11월9일 캡처·인물 초상·파형·과거 모바일 시안은 최신 기준에서 제거했다. 로컬 캡처와 합성 오디오 검증은 무시되는 `test-results/current-design/`에만 저장한다. 검증 결과는 루트 `design-qa.md`에 기록하며 실제 운영 계정·업스트림 음성 품질·운영 배포 검증과 구분한다.

## 원본 영상 비교 후 모션 보강 · 2026-11-17

사용자가 제공한 원본10초·60fps 영상을 실제 연속 프레임으로 비교했다. 포스터 기반 첫 구현의 제한적인 눈 길이 변화와 작은 기울기를 보강했다. 색·실루엣·UI는 그대로 유지한다.

- 캡슐·작은 점·가로 타원·휘어진 눈을 원본 눈 이미지의 회전/축 변형/곡률 변화로 표현한다. 기울어진 Alex 눈은 실제 눈 픽셀의 주축을 구해 변형하므로 점/타원 전환 시 찌그러진 사각형처럼 보이지 않게 한다. 가로 눈은 두 눈 사이를 넘지 않도록 폭을 제한한다.
- `gestureBeat`가 이동→유지→복귀→휴식 구간을 제공한다. 눈은 먼저 움직이고 몸은100ms 늦게 따라온다. 같은 상태를 반복 통지받아도 상태 시계를 재시작하지 않으며 실제 상태가 바뀔 때만 재시작한다.
- Alex는 집중한 시선과 작은 점 눈, Mia는 긴 여운과 휘어진 눈, Juno는 가로 타원과 반대 방향 기울기를 중심으로 구분한다. 모든 캐릭터가 똑같은 동작을 속도만 다르게 재생하지 않는다.
- 실제 입력/출력 음량과 무관한 발화 맥동은 여전히 만들지 않는다. 음소거·끼어들기·오류·종료·동작 줄이기·정지 대체 이미지는 앞선 규칙을 유지한다.

원본의 표정/자세/동작 사이 멈춤을 참고한 앱 상태 모션이며 원본 시퀀스나 타이밍을 그대로 복제한 것은 아니다.
