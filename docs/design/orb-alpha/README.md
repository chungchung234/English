# 캐릭터 외곽 파편 수정

2026-11-10. iPhone 사용자가 구체 바깥에 흰색·청록색의 깨진 띠가 보이며 주변 UI가 초점 효과처럼 어둡게 보인다고 보고했다. 최초 일반 캡처에서는 무늬가 거의 보이지 않았으나, 이후 이미지 선택 영역이 포함된 캡처에서 파편 형태가 드러났다. 스마트 반전은 꺼져 있다는 사용자 확인을 받았다.

## 확인한 결함과 변경

- 승인 원본의 본체 바깥에 알파 1/255 등을 가진 픽셀 흔적이 있었다. Alex의 비영점 알파 범위는 이미지 전체에 가깝지만, 알파 8/255 이상 범위는 본체 경계로 좁혀진다. 소스의 무늬가 사용자 캡처의 깨진 띠 형태와 대응한다.
- 원본 파일은 보존한다. 공통 디코딩 단계에서 알파 8/255 이하의 RGBA를 0으로 만들고 그 이후 텍스처를 축소한다. 본체 색이나 화면 전체의 밝기를 낮추는 처리는 하지 않는다.
- WebGL의 컨텍스트·텍스처 업로드·셰이더 출력을 premultiplied alpha로 통일하고 출력 색 공간을 지원하는 브라우저에서는 sRGB로 명시한다. ImageBitmap의 브라우저별 알파/방향 옵션 대신 정리한 Canvas2D 소스를 업로드한다.
- GPU 대체 이미지와 스와이프 미리보기도 정리된 동일한 원본 처리를 공유한다. 스와이프 중 이전 캐릭터의 스냅샷은 수정된 WebGL 출력을 사용한다.
- 최근 배포된 대기 호흡·기울기·윤곽 변화, 음성 반응, 좌우 전환 및 기존 통화 이후 흐름을 유지한다.

## 검증과 한계

실제 Chromium WebGL에서 reduced motion으로 고정한 세 캐릭터를 모바일 DPR 3 설정으로 렌더링했다. 아래 수치는 440×440 GPU 버퍼에서 알파가 128/255 이상인 본체로부터 3픽셀 이내의 정상 가장자리를 제외하고 센, 본체와 떨어진 비영점 알파 픽셀 수다.

| 캐릭터 | 수정 전 | 수정 후 |
| --- | ---: | ---: |
| Alex | 27,405 | 0 |
| Mia | 517 | 0 |
| Juno | 471 | 0 |

[원시 측정](verification.json). 이 수치는 픽셀 수준의 잔여 무늬 확인이며 실제 iPhone 디스플레이 측정이 아니다. `test/ai-presence.mjs`에서 외곽 파편 없음, premultiplied 출력의 RGB≤alpha 조건, 대체 이미지의 투명 외곽, 대기 호흡, 실제 합성 음성에 따른 윤곽/내부 변화, 오디오 자원 해제를 검사한다. 전체 브라우저 회귀 검사는 로그인·스와이프·통화·복습과 배포 CSP를 확인한다.

홈 코드에는 주변 UI를 어둡게 하는 초점/비네팅 효과가 없다. 주변 어두워짐까지 같은 원인인지, iPhone의 실제 표시 경로에서 해결됐는지는 실기기 확인 전 확정하지 않는다. 사용자의 밝기 설정이나 스마트 반전을 원인으로 단정하지 않는다.
