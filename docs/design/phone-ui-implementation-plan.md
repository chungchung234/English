# 모바일 연락처·통화 UI 구현 계획

2026-11-10 한국 시간. 사용자 요청: 최신 승인 AI 캐릭터를 기준으로 검토한 개선 항목을 계획하고 구현·배포한다.

## 구현 범위

1. 연락처: Alex·Juno·Mia를 한 번씩 표시. 이름 검색, 상대 상세, 바로 전화. 하단은 연락처·최근 통화·복습.
2. 상대 상세: 승인 AI 형상·이름·성격, 발신, 기억 관리, 지난 대화. 즐겨찾기·주제 선택·더보기·쉽게는 제공하지 않는다.
3. 통화: 어두운 모바일 화면, 경과·남은 시간, 음소거·힌트·대화문·종료. 최초 연결부터 최대20분이며 재연결·기억 정리로 연장하지 않는다. 종료 시 마지막 전사와 저장을 확인한다.
4. 자연스러운 대화: 새 회차에 자유 대화 맥락을 저장하고 역할극 시작 지침을 정리한다. 과거 회차의 주제 메타데이터는 원문 이력으로 보존한다.
5. 모션 복구: 같은 통화의 연결 복구 때 입력·출력 분석기를 다시 연결하고, 늦게 도착한 이전 연결 이벤트는 현재 통화를 덮어쓰지 않는다.
6. 자산: 승인 PNG 원본 보존. RGBA 픽셀이 동일한 무손실 WebP로 배포 인코딩만 최적화하고, 큰 이미지는 HTML에서 분리·해시 파일명으로 캐시한다.

## 역할과 모델

기존 사용자 요청의 모델 티어링을 이어서 설계 검토(Astra), 통화·서버 로직(Sol), 합의된 HTML/CSS 구현(Luna), 주 에이전트의 자산·통합·브라우저 검증·배포로 나눈다. 파일 소유권을 분리하고 최종 검토를 거친다.

컬러는 프로젝트의 impeccable-colorize 지침을 적용한다. 기존 브랜드 블루·네이비와 승인 캐릭터의 원래 색을 유지한다. 발신은 녹색, 종료는 빨간색으로 의미를 구분하고 글래스는 플로팅 컨트롤에 한정한다.

## 검증·완료 기준

- 390×844, 320×568, 안전 영역과 확대 글자에서 연락처·상세·통화·기록·복습을 확인한다.
- 새 상대 선택·다시 걸기 시 서버에 정확한 companion_id가 전달되고 상대별 기억 경계를 유지한다.
- 힌트 중복 요청, 수동/시간 종료 겹침, 전사·저장 실패, 끊김·복구, 백업·복원, 비승인 접근을 확인한다.
- 20분 상한을 브라우저 시간 가속으로 검증하고, 재연결 후에도 같은 종료 시각이 유지되는지 확인한다.
- 승인 캐릭터의 정지·음성 반응·동작 줄이기·GPU 대체 표시를 검증한다.
- 배포용 CSP 및 별도 이미지 경로가 GitHub Pages 하위 경로에서 동작하는지 확인한다. HTML과 필요한 이미지 바이트 수를 이전4.17MB HTML과 비교한다.
- 전체 검사 통과 후 배포한다. 승인 사용자 실기기·실제 모델 통화와 모의 테스트의 범위는 구분한다.

## 구현 완료

위 여섯 범위를 구현했다. 통화 종료/재연결/상대 전환의 경합을 검토하고, 전체 71개 테스트·기억 평가 10개·렌더러·모바일 브라우저 검사를 통과했다. 작은 화면의 125% 글자에서는 통화 내용을 스크롤하며 종료 버튼을 고정한다. 정량 결과와 합성 화면 증거, 실제 iPhone에서 남은 검증은 [모바일 검증 기록](phone-ui-qa.md)에 정리했다.
