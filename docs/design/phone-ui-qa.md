# 모바일 전화 UI 검증

> 최신 통화 홈은 [글래스 통화 홈 검증](call-glass/README.md)을 따른다. 아래 연락처 → 상세 구조와 최초 연결부터 남은 시간 표시 방식은 이전 릴리스 기록이다.

2026-11-10 한국 시간. 최신 승인 AI 캐릭터를 보존한 연락처·통화 화면 구현 기록이다. 이전 단일 홈 검토의 [다섯 항목](deployed-design-review-20261110.md)을 적용했다.

## 적용 결과

- 연락처 → 상대 상세 → 통화. 연락처 전화 버튼과 최근 통화의 다시 걸기는 해당 상대에게 바로 연결한다. 최근 통화는 전체 상대, 상세의 지난 대화는 선택한 상대 범위다.
- 즐겨찾기·주제 선택·더보기·쉽게 제거. 자유로운 일상 대화와 음소거·힌트·대화문·종료만 제공한다. 힌트는 AI 응답·발화 중 중복 요청을 막는다.
- 최초 연결부터 경과·남은 시간을 표시하고 20분에 마이크를 중지한다. 끊김·복구·기억 정리는 종료 시각을 연장하지 않는다. 자동으로 다음 통화를 시작하지 않는다.
- 일시 끊김 후 입력·출력 음성 분석기를 복구한다. 이전 통화의 늦은 이벤트는 현재 통화에 들어오지 않는다. 최종 연결 실패도 종료·저장 절차를 수행한다.
- 승인 PNG 원본을 보존하고 픽셀이 동일한 무손실 WebP를 외부 해시 URL로 제공한다. 로그인 전에는 캐릭터 이미지를 요청하지 않고, 가려진 렌더링 표면은 계속 그리지 않는다.

## 검증 결과

| 검사 | 결과와 범위 |
| --- | --- |
| `npm run check` | JavaScript 문법·Deno 타입 검사 통과 |
| `npm test` | 71/71 통과. 인증·SQL/RLS·기억 격리·저장/복원·분석·배포 자산 검사 포함 |
| `npm run eval:memory` | 10/10 통과. 실제 SQL과 합성 벡터 평가이며 언어 모델의 의미 이해 품질 측정은 아님 |
| `npm run test:presence` | 세 실제 이미지, GPU 렌더링, 합성 오디오 트랙 반응, 동작 줄이기, 분석기 해제, WebGL 대체 표시 통과 |
| `npm run test:browser` | Chromium 390×844·320×568의 연락처/상세/통화/기록/복습, 실제 배포 구조의 CSP·하위 경로 자산 로딩 통과 |
| 시간·연결 경계 | 모의 통화를 10분 진행 → 2분 끊김 → 7분 복구 후 19분 유지, 20분에 마이크 중지·전사 저장·피드백. 동일 종료 중복 호출 1회 처리 |
| 실패·상대 경계 | 시작 실패 후 재시도, 최종 연결 실패, 저장 성공 후 이력 조회 503, 다른 상대를 선택한 상태의 다시 걸기, 이전 연결의 늦은 전사 검증 |
| 모바일 배치 | 작은 화면에서 발신·종료 접근 가능. 통화 글자 크기를 125%로 키운 검사에서 조작/대화문 겹침 없이 스크롤 가능. 안전 영역은 CSS `env()`로 반영 |
| 기존 기능 | IndexedDB 재전송·정확한 UUID, 기억 수정/잊기/제외/복구, XSS 방어, JSON 백업·복원, 비승인 계정의 데이터 요청 차단 유지 |

모의 업스트림 응답·합성 데이터로 검사했으며 실제 사용자 기록에 접근하지 않았다. 음성 분석기 복구는 실제 브라우저 AudioContext와 생성한 오디오 트랙으로 확인했고, 원격 AI 제공자의 연결 자체는 대체했다. 화면 캡처는 같은 합성 데이터 검사에서 생성했다.

## 전송 크기

압축 해제 기준, MB는 십진 단위다. HTTP 압축 전후 지연 시간 측정 결과가 아니다.

| 자산 | 변경 전 | 변경 후 |
| --- | ---: | ---: |
| HTML | 약4.17MB, PNG base64 포함 | 약169KB, 앱 코드·작은 아이콘 포함 |
| 세 캐릭터 원본 바이너리 | PNG 합계3,032,084바이트 | WebP 합계1,465,416바이트 |
| HTML + 세 캐릭터 전체 | 약4.17MB | 약1.63MB |

각 WebP의 크기는 Alex 515,878, Mia 491,026, Juno 458,512바이트다. 세 자산 모두 1254×1254이며 원본 PNG를 RGBA로 읽은 전체 픽셀 바이트와 정확히 일치한다. 해시 URL은 변경되지 않은 이미지를 재사용하도록 하며, 실제 캐시 기간은 호스트 정책을 따른다. `_headers`의 immutable 설정이 GitHub Pages에서도 그대로 적용된다고 가정하지 않는다.

## 남은 실기기 확인

실제 iPhone Safari의 마이크 권한·백그라운드/잠금·네트워크 변경·GPU/배터리, 승인 계정의 실제 AI 음성 통화는 별도 확인이 필요하다. Chromium 크기 조절과 글자 확대는 iOS Dynamic Type 또는 실제 안전 영역 기기 시험을 대체하지 않는다. 기존 승인 정책을 바꾸어 이 검증을 우회하지 않는다. SMTP 전달·관리형 DB 재해 복구는 이번 UI 구현 범위 밖의 기존 운영 과제다.

## 공개 배포 확인

- 앱 커밋 [`7bc1c66`](https://github.com/chungchung234/English/commit/7bc1c66ca29c94af65e874a69d01fbaa4bf85873), [배포 검사 성공](https://github.com/chungchung234/English/actions/runs/42668898340). 백엔드·Pages 게시 및 비승인 계정의 DB·기억·AI 접근 거부를 확인했다. 승인 계정의 실제 음성 통화 검사는 실행하지 않았다.
- 2026-11-10 02:57 KST, 공개 HTML·세 WebP의 HTTPS 응답 200. HTML은 169,083바이트이며 세 이미지는 저장소의 배포 원본과 바이트 단위로 일치한다. [SHA-256·URL·검사 메타데이터](phone-ui/deployed/verification.json).
- [게시 파일의 연락처](phone-ui/deployed/contacts.png), [Mia 상세](phone-ui/deployed/detail.png), [작은 화면](phone-ui/deployed/compact.png), [로그인](phone-ui/deployed/login.png).

화면은 HTTPS로 받은 게시 파일을 변경 없이 같은 URL·CSP에서 렌더링하고, 이미지 디코딩 완료 후 촬영했다. 환경의 신뢰된 HTTPS 프록시로 가져온 파일을 브라우저에 전달했으며 보호된 API는 모두 합성 응답으로 대체했다. 실제 이용자의 계정·기록이나 제공자 음성에는 접근하지 않았다. 실행 오류 0건, 세 연락처 표시, 작은 화면의 가로 넘침 없음과 발신 버튼 위치를 확인했다.
