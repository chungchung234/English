## 사용자에게 보이는 흐름

1. 종료 입력 즉시 마이크·재생·통화 조작을 정지하고 종료음을 낸다. 600ms 종료 연출 뒤 받은 대화를 먼저 연다. 600ms는 화면 연출 값이며 측정한 저장 시간이 아니다.
2. 마지막 전사와 저장이 끝나기 전에는 ‘마지막 대화 확인 중’을 표시한다. 서버의 올바른 `finish_session` 응답 뒤에만 저장 완료로 표시하고 피드백을 요청한다.
3. 원문 하단의 예약 공간이 ‘피드백 준비 중’에서 ‘피드백 보기’로 바뀐다. 준비 완료는 화면이나 읽던 위치를 바꾸지 않는다.
4. 피드백은 별도 화면에서 실제 발화에 근거한 관찰, 유용한 교정·대안, 다시 쓸 표현을 보여준다. 표현 1개 제한이나 필수 항목 수를 두지 않는다. 긴 출처는 ‘발화 일부’로 명시하고 전체 원문에 연결한다.
5. 원문에서 보기로 해당 발화를 강조한다. 피드백으로 돌아가면 피드백 위치를, 상단 대화 기록으로 돌아가면 원래 원문 위치를 복원한다. 아직 도착하지 않은 원문도 기다리되, 다른 화면·회차로 이동한 뒤에는 포커스를 가져오지 않는다.
6. 마치기는 화면만 닫는다. 연습·완료·미루기를 기록하지 않는다. 저장 중 나가도 이후 저장 완료가 화면을 다시 열지 않는다. 저장·재시도 실패와 사용자 발화 없음은 별도로 안내한다.

‘생각할 시간’ 버튼, 혼자 말하기 진입, 통화 중 벽시계·기억 전달 설명·평상시 저장 문구를 없앴다. 음성 대화 제어, 실제 시간/시간대 저장, 기억 검색, 종료/연결 소리는 유지했다. 기존 과거 연습 데이터·제외·보류·재검토·예약 회상 기능의 서버 호환성과 계정 보호도 유지했다. 캐릭터가 먼저 종료하는 기능은 [검토 문서](../../character-initiated-hangup-review-20261111.md)에만 남겼다.

## 크기와 시각 설계

- 앱 너비 최대 460px, 좌우 여백 22px. 390×844와 320×568, 루트 글자 200%를 검사했다.
- 원문 영어 17px/1.55, 제목 24px, 피드백 제목 28px, 내용 제목 18px. 한글 제목은 단어 기준으로 줄바꿈한다.
- 상단 높이 최소 64px, 마치기·뒤로가기 터치 영역 최소 44px. 준비 완료 버튼 높이 최소 56px.
- 하단 예약 영역 기본 96px + 안전 영역. 큰 글자/오류로 필요한 높이를 측정하여 본문 하단 여백에 반영하고, 같은 회차에서는 준비 완료 때문에 줄어들지 않는다.
- 기존 화이트·남색·코발트 토큰과 기존 Phosphor 아이콘을 사용한다. ‘기록 정보’와 ‘피드백 관리’는 닫힌 보조 영역이다.
- 근거 없는 발음·유창성·듣기·레벨 점수와 예상 생성 시간/진행률을 만들지 않는다. 교정 이유가 짧으면 항목 제목으로 사용하며, 같은 설명을 아래에 반복하지 않는다.

- `npm run check`, `npm test` 228/228, `npm run build` 통과.
- 브라우저 12개 스위트: 기존 10개와 원문 안정성·별도 화면 상태 회귀 2개. 인증·승인 정책·소유권·오프라인 보관·정확한 저장 ACK·마지막 전사·부정확한 ACK·재접속·충돌·CSP·기존 기록 복원 검증을 유지했다.

- 생성 완료/늦은 발화/저장 상태 갱신 시 원문 위치 유지, 출처 왕복, 만료된 피드백 숨김, 다른 회차의 재시도/출처 응답 차단, 실제 피드백을 연 후에만 열람 기록을 확인했다.
- 캐릭터 렌더링, 기억 평가, 학습 기능 합성 평가 통과. 학습 효과나 사람의 교정 품질을 증명하는 실험은 아니다.

실제 승인 계정으로 새 음성 통화를 수행한 결과나 6–8명 사용자 관찰 결과는 이번 증거에 포함하지 않는다. 공개 배포 결과는 해당 PR의 검증 기록에 추가한다.
