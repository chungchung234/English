## 기준

현재 소스 `67c4bc9`의 기존 검수 캡처인 [날짜별 목록](../../research/review-boundaries-20261111/verification/date-list.png)과 [통화 학습 노트](../../research/review-boundaries-20261111/verification/call-note.png)를 직접 확인하고 각 이미지 생성에 실제 파일로 첨부했다. 공개 사이트의 스크립트 빌드 `git:1743dbf0c6dd16902c809ec30cb9ebc64838d802`도 확인했다. 이 시안은 새로 로그인해 캡처한 운영 화면이 아니다.

기존 흰색·네이비·블루, 로고와 내비게이션, 날짜 단일 표기, 표현별 중립 경계를 유지한다. 통화일은 2026년 11월 10일로 통일했다. 교정·일상 구어·잘 쓴 표현의 문구는 가상 사례이며 유형별 생성 할당량이 아니다.

## 최신 수정 기준과 표시 순서

사용자는 수정 세트의 **1번**을 선택하고 타입을 간단하게 표시하도록 추가 지시했다. [짧은 타입 하나만 남긴 최종 기준](selected-simple-types.png)이 구현 대상이다. 모든 카드와 상세에 ‘교정’, ‘일상 구어’, ‘잘 쓴 표현’ 같은 짧은 라벨 하나를 같은 위치에 표시한다. 피드백 방식과 세부 학습 영역은 내부 데이터에서 구분한다.

사용자는 목록의 한 항목에 해당하는 상세만 보여야 하며 모든 항목에 타입을 붙이도록 지시했다. 아래 최신 세 이미지는 이 수정을 반영한다. 상세에는 선택한 `I'm down` 한 건의 뜻·질문·쓰임·사용 예·대안만 남기고, 같은 통화의 다른 표현은 제거했다. 원래 시안의 통화 전체 상세 가정은 이 지시로 대체됐다.

아래 번호는 수정 이미지가 대화에 실제 표시된 순서이며, 이후 선택된 1번에 짧은 타입 지시를 반영한 최종 기준은 위 링크다.

| 번호 | 파일 | 비교할 정보 배치 |
| --- | --- | --- |
| 1 | [한 표현 바로 읽기](single-expression/01-direct-reading.png) | 표현·뜻을 먼저 읽고 같은 흐름에서 질문 맥락·쓰임·대안을 확인 |
| 2 | [한 표현 뜻과 쓰임](single-expression/02-meaning-and-use.png) | 표현·뜻·질문은 유지하고 상세의 뜻·맥락과 쓰임을 전환해 읽음 |
| 3 | [한 표현 맥락에서 배우기](single-expression/03-context-first.png) | 사용자가 물어본 의도를 먼저 제시한 뒤 표현·쓰임·사용 예로 연결 |

이 수정 세트의 두 부분으로 된 타입 줄은 이후 ‘짧은 라벨 하나’라는 사용자 지시로 대체됐다. 타입별 색상을 늘리지 않는다.

## 초기 시안 보존

루트의 [초기 바로 읽기](01-direct-reading.png), [초기 뜻과 쓰임](02-meaning-and-use.png), [초기 맥락 우선](03-context-first.png)은 수정 전 비교 자료다. 현재 선택 대상은 위 `single-expression` 폴더의 수정 이미지다.

목록의 저장과 상세 이동은 다른 행동이다. 실제 사용자 질문, AI 제안, 사용 예, 잘 쓴 실제 표현을 구분한다. 다음 통화 연습 버튼이나 유형별 필터, 강제 퀴즈, 새로운 관리 화면은 추가하지 않았다.

이미지는 시각 탐색 결과다. 이후 실제 HTML/CSS와 합성 통화 데이터로 목록·상세·저장·원문·복귀, 모바일·큰 글자·키보드와 지연 응답을 검사했다. [시각 비교 자료](verification/comparison-full.png), [영역 비교](verification/comparison-focus.png)와 [최신 디자인 검수](../../../design-qa.md)를 참고한다. 실제 학습자의 이해도나 학습효과를 검증한 결과는 아니다.
