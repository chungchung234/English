# 말하기 속도

통화 화면의 음소거와 힌트 사이에 있는 ‘속도’를 누르면 하단 패널이 열린다. 0.5~1.5배를 0.05 단위로 선택하며 기본은 1.0배다. 드래그는 초안만 바꾸고 ‘적용’으로 확정한다. 닫기·Escape는 초안을 취소한다.

AI 응답 생성과 출력 재생이 끝난 뒤 기존 WebRTC 데이터 채널로 `session.update`의 `audio.output.speed`만 보낸다. 서버의 `session.updated`에서 배속을 확인해야 현재 배속과 설정 저장을 갱신한다. 대기 중에는 기존 배속과 별도로 대기 상태를 표시한다. 변경 오류·시간 초과는 전사 실패로 처리하지 않는다. 종료된 통화의 지연 응답은 다음 통화에 반영하지 않는다.

마지막으로 확인한 배속은 브라우저에 서비스 URL·사용자 ID 범위로 저장하며 같은 계정의 다음 통화에서 초기 설정으로 전달한다. 상대별 설정이나 기기 간 동기화는 제공하지 않는다. DB 마이그레이션은 없다. 서버는 누락된 배속을 1로 처리하므로 과거 웹 클라이언트와 호환된다. **함수 먼저, 웹 나중** 순서로 배포한다.

디자인 및 검증 증거는 [프로젝트 QA](../../../design-qa.md)의 ‘말하기 속도 슬라이더’를 참조한다. 현재는 로컬 구현이며 실제 음성 제공자 응답은 모의 값으로 검증했다.
