# 최근 통화·복습 개선 검수

2026-11-10. 기존 통화 홈의 컬러·글래스·캐릭터를 유지하면서, 사용자가 진행을 요청한 네 보완 항목을 반영했다.

## 반영한 동작

- 최근 통화: 한 행에 상대·날짜와 플랫한 다시 걸기 아이콘을 표시한다. 행을 누르면 해당 통화 상세를 열고 피드백·대화문·기억 제외·재확인을 이용한다. 관리 기능은 기본적으로 접는다.
- 통화 상세는 조회만으로 선택한 AI를 바꾸지 않는다. 피드백 열기·다시 걸기·기억 변경 시 해당 상대를 명시적으로 사용한다. 늦게 도착한 대화문은 닫힌 상세나 다른 통화에 들어가지 않는다.
- 열어둔 통화 상세의 동작은 목록 재조회와 분리한다. 목록이 갱신돼도 같은 로그인 범위의 현재 상세에서 피드백을 열 수 있고, 닫힌 상세의 이전 버튼은 동작하지 않는다.
- 긴 대화문은 본문 안에서 스크롤되며 닫기 버튼은 유지한다. 실제 앱의 API·저장·기억 격리 방식은 유지한다.
- 복습: 교정 문장 → 연습 표현을 먼저 보여준다. 요약·분석 범위·잘한 점·패턴은 ‘통화 돌아보기’로 펼친다. 교정이나 연습 항목이 없을 때는 요약을 바로 표시한다.
- 교정 전 문장 색을 `#59647c`로 맞춰 흰 배경 대비를 3.61:1에서 5.93:1로 개선했다.
- 현재 피드백과 겹치는 지난 표현 미리보기는 반복하지 않는다. 관련 피드백이 없을 때는 이전 표현 진입을 유지한다.
- 주간 분석은 선택한 상대의 최근 7일 내 종료 통화가 있을 때만 표시한다. 최근 30개 목록 밖의 통화도 별도 조회로 확인한다. 중복 클릭을 막고 결과는 복습에 표시한다.
- 빈 상태에서는 검색·기억 관리·주간 분석 등 아직 쓸 데이터가 없는 조작부를 나열하지 않는다. 기존 통화 탭으로 시작할 수 있다.
- 대화 검색은 기존 상대별 기억 범위를 유지하고 입력란에 대상 이름을 표시한다.

## 검증

- `npm test`: 82/82 통과. `npm run check` 통과.
- 전체 브라우저 회귀 검사 및 새 탭 전용 브라우저 검사 통과. 교정 우선순위, 글자 대비, 캐시된 피드백 열기, 긴 대화문 닫기 접근, 늦은 응답 격리, 빈 상태, 7일 범위, 30개 밖의 주간 대상, 주간 요청 중복 방지와 결과 표시를 확인했다.
- 기존 로그인 유지·Google/카카오 연결, 상대별 다시 걸기, 저장·복습·기억 제외/복구, 20분 종료 흐름도 회귀 검사했다. 제공자 응답·음성 연결은 모의이며 실계정 통화 성공을 주장하지 않는다.
- 390px/320px 가로 넘침 없음, 캡처 실행 오류 0건.
- 배포 HTML은 생성 코드의 달러 문자가 변형되지 않도록 치환 함수를 사용한다. 실제 인라인 스크립트와 CSP 해시 일치 검사를 통과했으며 정책을 완화하지 않았다.

웹 글래스 표현이며 애플 네이티브 Liquid Glass API는 사용하지 않는다. 실제 iPhone Safari·스크린리더 전체 적합성은 별도 확인 범위다.
