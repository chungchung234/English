## 재현

```sh
npm run eval:memory
npm run check
npm test
npm run test:browser
```

## 해석과 남은 평가

이 결과는 실제 SQL의 검색 및 기억 정책 동작을 측정한다. 벡터를 사람이 지정했으므로 `text-embedding-3-small`의 한국어·영어 의미 이해도, 실제 검색 정밀도·회수율, 자연스러운 회상 또는 영어 학습 효과를 입증하지 않는다. 위 합성 회수 결과를 서비스 전체의 성공률로 표시하지 않는다.

실제 모델 품질 평가에는 승인 계정의 동의된 표본으로 한국어↔영어 바꿔 말하기, 서로 비슷하지만 다른 주제, 시간에 따라 바뀐 사실, 추측하면 안 되는 정보, 상대별 경계를 평가해야 한다. 사용자의 운영 접근 승인 설정은 검증용으로 완화하지 않는다.

같은 PGlite 연결의 시험만으로 실제 PostgreSQL 다중 연결의 모든 경쟁 순서를 증명하지 않는다. SQL은 기억 상태 잠금과 통화 생성 트리거를 사용하고, 서버는 AI 응답 전후의 기억 버전을 검사한다. 다중 연결 부하·실제 장시간 음성 테스트는 별도 통합 평가 범위다.
