## 모델·캐시·비용 정책 (2026-11-10)

- `supabase/functions/coach/policy.ts`에서 모델·추론·가격을 관리합니다. 교정과 중간 정리는 Luna low, 주간 분석은 Sol medium이며 `CHECKPOINT_REASONING`도 지원합니다. 교정·중간 정리 출력 예산은 추론 포함6,000토큰, 주간 분석12,000토큰입니다. 간결한 한국어 설명과 기존 인용 검증을 유지합니다. Standard 처리, 모델 호출당35초 제한(요청당 최대2개 분할 호출로 기존90초 클라이언트 제한 안에서 처리), 자동 유료 재시도 없음.
- 결과 캐시는 사용자·상대·원문 전체 해시·회차/UTC일자와 모델·추론·출력·스키마·시나리오·정책 버전을 반영합니다. 프롬프트 변경 시 `POLICY_VERSION`을 올려야 합니다. 같은 요청의 결과 재사용에는 새 모델 호출·비용 예약이 없습니다.
- 공급자 프롬프트 캐시는 공통 developer 지침 끝에만 explicit breakpoint를 둡니다. 사용자 전사문에는 breakpoint를 두지 않으며, 실제 재사용 여부는 cached_tokens로 측정합니다. 별도 cache key·장기 보존·서버 대화 상태는 추가하지 않습니다. `store:false`는 ZDR 보장이 아닙니다.
- `model_spend`는 서버 전용으로 호출별 입력·출력·캐시 읽기/쓰기·추론 토큰, 모델·정책·추정 USD를 저장합니다. 출력 토큰에는 추론이 포함되므로 추론 비용을 이중 계산하지 않습니다. 불완전·잘못된 분석에도 사용량을 기록합니다. 사용량이 없거나 네트워크 결과가 불명확하면 금액을0으로 표시하지 않고 null로 남깁니다.
- 분할 분석·중간 정리·임베딩을 포함한 UTC 일일 텍스트 예약 예산은 사용자당 $1입니다. 입력 바이트+여유분과 최대 출력으로 보수적으로 선예약하고, 실패·시간초과도 환불하지 않습니다. 사용자별 동시 요청은 DB 잠금으로 직렬 예산 검사합니다. 이는 앱의 추정 예약 제한이며 OpenAI 청구서의 확정 상한이 아닙니다. 가격 변경 시 정책 가격도 갱신해야 합니다.
