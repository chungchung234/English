# 통화 이후 흐름 · 구현 기록

2026-11-10. 사용자가 전달한 「시시콜콜 — 통화 이후 플로우 기획안」을 기준으로 반영했다. 원문의 ‘기획 초안, 구현 보류’ 상태는 이후 사용자의 반영 요청으로 이 문서에 명시한 범위에서 구현으로 전환했다. 색·캐릭터·플랫 발신 버튼·글래스 조작부는 기존 디자인을 따른다.

## 반영 범위

- 마지막 전사·클라우드 전송·회차 종료 확인이 끝나야 저장 완료로 안내한다. 일부 전사가 누락되거나 전송에 실패하면 기존 기기 대기열과 미완료 회차를 유지한다. 기록 상세에서 대화문을 확인하고 ‘수신된 기록으로 종료’를 명시적으로 선택할 수 있다.
- 저장 확인 후 복습을 열고 분석을 별도로 준비한다. 분석 중에는 탭 이동과 다음 통화가 가능하다. 늦은 분석 완료는 화면을 강제로 전환하지 않으며 다른 상대·회차·계정의 화면을 덮지 않는다.
- 분석 실패는 대화 저장 실패와 분리하고 해당 회차의 재시도 버튼을 제공한다. 새로고침 이후에도 기록 상세에서 다시 생성할 수 있다. 생성은 기존 원문 해시·예약·중복 방지 정책을 사용한다.
- 핵심 화면에는 요약, 잘한 점 하나, 교정 최대 두 개를 보여준다. 전체 교정·근거·부가 분석은 기존 펼침 구조에서 확인한다. 빈 배열을 인위적으로 채우지 않는다.
- 해당 회차의 최신 분석에서 근거가 있는 교정·추천 표현을 중복 제거해 최대 세 개 저장한다. 기본 행동은 한 표현을 연습하는 것이다.
- 보고 말하기·가리고 말하기, 나중에 하기·직접 연습함을 제공한다. 저장 응답을 확인한 후에만 상태를 바꾼다. 실패하면 표현과 재시도 조작을 유지한다. 직접 연습함은 자기 보고이며 숙달·발음·성취 점수가 아니다.
- 계정·상대·원본 회차·분석에 상태를 연결한다. 다음 방문과 기기 변경 시 같은 계정의 클라우드 상태를 읽는다. 일반 복습 진입은 남겨둔 표현을 먼저 안내하며 기록에서 선택한 회차는 해당 피드백을 연다.
- 통화 홈에는 남겨둔 표현 또는 지난 연습 표현을 표시한다. 추천 상황의 ‘다음 통화 준비’는 상대별로 클라우드에 저장하고 홈으로 이동한다. 마이크와 새 회차 생성은 ‘통화’를 눌렀을 때만 수행한다.
- 다음 통화의 서버 기억에는 직접 연습한 표현을 최대 두 개 우선 전달한다. 상대별 기억 제외·이력 제한을 적용하며 기존 페르소나 정의는 바꾸지 않는다.
- 표현 재사용은 연습 표시 이후 시작한 같은 상대의 종료 통화에서 **사용자 전사**를 확인한다. 대소문자·구두점·공백을 정규화한 연속 어구가 일치할 때만 원문·발화 ID·회차 ID·시각을 함께 반환한다. AI 발화, 다른 상대, 이전 회차의 지연 업로드, 의미만 비슷한 표현은 재사용 근거로 인정하지 않는다. 발음 평가는 하지 않는다.
- 늦은 발화 추가나 분석 재생성으로 원문 범위가 달라지면 이전 분석의 연습 항목을 큐와 다음 통화 기억에서 제외한다. 화면에서는 새 원문으로 재생성을 안내한다. 기존 자기 보고를 새 분석에 자동 승계하지 않는다.
- 주간 분석에는 저장된 실제 시작·종료 시각을 표시한다. 이후 통화가 포함된 것처럼 기간을 갱신하지 않는다.

## 데이터와 권한

`202611100004_learning_review.sql`은 `learning_items`, `learning_plans`와 승인·소유권을 검사하는 RPC를 추가한다. 브라우저는 연습 문장·소유자·근거를 임의로 삽입하지 못한다. 항목은 서버에 저장된 최신 분석과 사용자 전사에서만 생성한다. 읽기는 계정별 RLS, 쓰기는 제한된 RPC를 통한다. 분석·원본 회차 삭제 시 연결된 연습 기록도 제거한다.

기존 JSON 복원은 대화 원문과 기억 설정을 복구하는 기능이다. 새 연습 표시는 같은 계정의 클라우드에서 복원하며, 별도 파일로 연습 상태를 이관하는 기능은 이번 범위에 포함하지 않았다.

## 미확정 사항

전달된 문서는 ‘복습 주기 제안’ 제목에서 끝났다. 반복 주기·자동 알림·간격 반복·숙달 판정은 추가하지 않았다. 별도로 배포됐다고 언급된 페르소나 수정본은 이 작업에 전달되지 않았고, 확인한 원격 저장소 및 배포 함수에는 기존 정의가 있었다. 따라서 새로운 성격·소개 문구를 추정해 교체하지 않았다.
