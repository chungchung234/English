# 통화 이후 플로우 — 최종 디자인 통합·인수 검증

검증일: 2026-11-10 · 정책: [기획 기준선 r2](post-call-plan.md)

## 결과

**사용자가 확정한 최종 배포 디자인에 1차 기능을 통합했다.** 배포 기준선 `5937c9b`의 화면·스타일·이미지·모션·스와이프를 유지하고 기존 펼침 영역에 학습 기능을 연결했다. 이메일·소셜 인증, 승인 계정 제한, 기억 관리, 모델·비용 정책도 유지했다.

- `npm run check`: JavaScript 구문과 Deno 타입 검사 통과.
- `npm test`: 단위·DB·서버·복구 대기열·배포 패키지 테스트 **116개 통과**. 서버 52개, canonical 학습 DB 18개를 포함한다.
- `node test/browser.mjs`: 기존 통화·이력·복구·전체 내보내기·모바일·배포용 CSP 검사 통과.
- `node test/post-call.browser.mjs`: 실제 Chromium·IndexedDB·PostgreSQL 엔진(PGlite)·인증 역할·RLS·새 RPC에 연결한 인수 **16개 실행 그룹 통과**. 27개 T 식별자의 브라우저 경로, 320/390/1280px, 배포용 HTML CSP를 확인했다.
- 초기 독립 코드 검토에서 발견한 8개 경로를 수정했다. 최종 배포 기준선 통합 후 승인·소유권·기존 데이터 이관·기억 제외·체크포인트·CAS를 독립 재검토했으며 중대 결함은 발견하지 않았다.
- `npm run test:presence`: 세 캐릭터·무음 호흡·실제 합성 음성 트랙의 시각 반응·오디오 자원 해제·WebGL 대체 경로 통과.
- `npm run eval:memory`: 합성 벡터와 실제 SQL로 검색·격리·제외 정책 **10/10 통과**. 실제 임베딩 모델의 의미 이해 성능 평가는 아니다.

로컬 브라우저 인수의 외부 인증·OpenAI 응답·WebRTC 전송은 테스트 값이다. DB 동작과 역할·RLS·RPC·IndexedDB·화면 동작은 실제 로컬 실행이다. 실제 운영의 OTP 요청·암호화 스냅샷 복원은 [운영 보고서](production-readiness-20261110.md)에 별도 기록했다. 이 결과를 실제 운영 음성 품질·메일 전달·관리형 재해 복구·실제 사용자 관찰 통과로 해석하지 않는다. 게시된 버전과 배포 성공 여부는 [Actions](https://github.com/chungchung234/English/actions)를 확인한다.

추가 실제 운영 인수: 2026-11-10 19:36~19:39 KST Google 승인 계정으로 Alex와 실제 대화하고 사용자 6개·AI 7개 발화 및 피드백 1건 저장을 검증했다. 사용자가 새로고침 후 이력 복원을 확인했고, 운영 DB에서 동일 회차·전체 출처·인용·실제 생성 사용량을 대조했다. [실제 통화 보고서](live-voice-acceptance-20261110.md)에 사용자 확인과 서버 검증을 구분했다. RTC 연결 계측 수신은 별도 점검으로 남는다.

기존 `learning_items`·`learning_review`·`learning_plan`은 호환성을 유지한다. 새 마이그레이션 `202611100012_learning_state.sql`은 별도 `learning_state_items`와 지원 테이블·RPC를 추가하며 기존 수행·미루기 기록을 멱등 이관한다. 승인 취소·기억 제외·시간 경계·원문 버전 검사는 새 경로에도 적용한다. 앱과 공식 인증 SDK는 콘텐츠 해시 JS 파일에 묶고 SRI와 hash-only CSP를 검증하며, HTML은 약104KB다.
