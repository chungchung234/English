# 연구 기반 통화·복습 구현 및 배포 검증

기준일: 2026-11-10 UTC. [연구 종합 결론](research/english-learning-conclusions.md)을 실제 동작으로 연결한다. 기존 시각 디자인, 계정 승인·소유권, 저장·복구, 한국어 UI와 통화 후 설명을 유지한다. 이 기록의 소프트웨어 검증과 실제 음성·학습효과 검증은 별개다.

## 근거에서 구현으로

`semantic_vad / low`는 공식 API의 구현 후보이며 특정 한국인 학습자에게 최적임을 입증한 값이 아니다. 일정한 최소 대기 시간을 보장하지 않는다. 512토큰 상한은 기존대로 유지하고 생성된 문장·전사를 단어 수에 맞춰 잘라내지 않는다. 1·3·7일 복습 일정도 기존의 실용적 초기값이며 최적 간격으로 표시하지 않는다.

## 사용자 제어와 데이터 경계

- ‘생각 중’은 음소거와 별개다. 마이크와 자동 전사는 유지하면서 AI의 자동 응답을 멈춘다. 재개는 서버의 정책 적용과 출력 정리를 확인한 뒤 진행하며, 응답 확인에 실패하면 대기 상태에서 재시도 또는 통화 종료를 제공한다.
- 대기 중 힌트와 기억 압축처럼 응답을 발생시키거나 입력을 끊을 수 있는 조작을 막는다. 기존 음성 속도 제어와 통화 종료·계정 변경도 함께 검증한다.
- 종료 시 아직 확정되지 않은 발화도 기다린다. 자동 확정과 수동 종료 요청이 겹쳐 빈 입력 오류가 오면 해당 종료 요청임을 확인하고 실제 확정·전사 사건을 기다린다. 제한 시간 내 확인되지 않으면 완료로 표시하지 않고 기존 부분 기록·복구 흐름을 사용한다.
- 작은 화면에서 글자를 키웠을 때 대기 안내가 종료 버튼 아래에 가려지지 않도록 통화 내용에 스크롤 공간을 확보한다. 캐릭터·색·기존 통화 조작은 유지한다.
- 중단된 AI 출력에서 늦게 온 미저장 전사를 걸러도 이미 저장된 문장이 실제로 들은 전체 범위와 같다고 보장할 수 없다. 기존 저장 행을 임의 편집하지 않고 대화문에 이 한계를 알린다. 정확한 재생 구간을 복원했다는 주장을 하지 않는다.
- 즉시 연습은 교정 뒤 재표현에 관한 자기보고다. 답을 가려도 직전에 교정을 봤을 수 있으므로 독립 인출이나 숙달 증거로 바꾸지 않는다. 지연 회상 역시 자기보고이며 실제 발화·기억 여부를 독립 확인한 결과가 아니다.
- DB 스키마, 승인 계정 정책, API 키, 음성 원본 수집 정책은 변경하지 않는다. 자동 테스트는 승인 계정을 만들거나 가장하지 않는다.

## 검증 및 배포

단위 검사 **199/199**, 구문·Deno 타입 검사, 공개 설정을 포함한 배포 빌드, 기억 평가 및 합성 학습 평가가 통과했다. 캐릭터·오디오의 기존 5개 브라우저 검증도 통과했다. 합성 학습 평가는 실제 학습효과 측정이 아니다.

브라우저 검증 범위는 기존 로그인·승인·통화·속도·기록, 통화 후 복습, E01–E05, 종료 직후 대화문과 재접속, 새 발언권 제어, 새 회상 단서다. 실제 Chromium·마이크 트랙·IndexedDB를 사용하되 인증·DB·공급자/WebRTC 사건은 명시적 테스트 대역이다. 390px 및 320px·글자 확대 화면도 확인한다. 공개 서비스의 실제 인증 차단 검증은 배포 후 별도로 진행한다.

독립 검토에서 발견한 재개 전 출력 정리 확인, 취소 완료 사건 직후 힌트의 중복 응답 가능성, 회상 단서의 정답 노출을 보완했다. 최종 회귀와 배포 결과, 운영 빌드 식별자·Edge 버전·CI 실행 링크는 [PR #4](https://github.com/chungchung234/English/pull/4)에 기록한다. DB 마이그레이션과 키 교체는 추가하지 않는다.

실제 승인 계정의 새 음성 통화는 이 변경의 자동 검사에 포함되지 않는다. 모의 WebRTC·공급자 응답으로 검사한 결과를 모델의 실제 응답 길이, 한국어 입력 처리 성공률, 끼어듦 감소율, 장기 학습효과로 보고하지 않는다. 빈 출력 버퍼 정리 확인을 포함한 실제 WebRTC ‘생각 중 → 다시 대화’와 한국어 요청에 대한 실제 음성 준수는 승인 계정 통화에서 추가 확인할 항목이다.
