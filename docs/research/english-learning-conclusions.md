# 시시콜콜: 영어 학습·대화 연구에 따른 설계 결론

조사 기준일: **2026-11-10 UTC**. 현재 문제는 통화 뒤 기록 접근, AI의 빠른 끼어듦, 장황한 답변, 한국어 입력에 따른 한국어 음성 전환이다. 이 문서는 이 문제들을 영어 학습 과정 전체와 연결해 내린 결론이다.

후속 구현과 검증 상태는 [연구 기반 구현·배포 기록](../research-implementation-release-20261110.md)에서 별도로 추적한다. 아래의 ‘현재 상태’ 표는 연구 당시 배포 기준이다.

전화 영어 목적에 따른 페르소나·현재 시각·이전 대화 연결의 후속 설계는 [전체 고도화안](../phone-english-upgrade-20261111.md)과 [전화 영어 목적 연구](phone-english-purpose.md)에 이어진다.

## 채택할 방향

**사용자가 영어로 자기 뜻을 말할 시간을 확보하고, AI는 그 뜻에 짧고 적절하게 반응한다. 막히면 필요한 도움을 주고, 통화 뒤에는 원문 확인 → 선택한 부분의 교정 → 자기 말로 재표현 → 나중에 다른 상황에서 사용으로 연결한다.**

이 학습 구조를 설계에 채택할 근거는 충분하다. 특정 대기 초수·단어 수·반복 횟수가 보편적 최적값이라는 근거는 없다. 두 판단을 분리해야 한다. 현재 서비스의 장기 학습효과를 입증했다는 뜻은 아니지만, 모든 기획 결정을 사용자 실험 전까지 보류할 이유도 없다.

## 조사 범위와 해석

제2언어 상호작용과 산출, 과제·반복, 생각할 시간과 턴 전환, 설명의 길이와 이해, 구두 교정과 피드백 시점, 전사·자기 알아차림, 인출·분산 연습, AI 말하기 학습, 모국어 활용, 동기·불안, 언어능력 평가를 검토했다. 메타분석·체계적 검토를 우선 찾고, 한국인·음성 대화의 직접 연구와 반례·방법론 비판을 함께 읽었다. 교육 기준과 API 명세는 각각 규범·기술 근거로 구분했다.

검색 가능한 모든 문헌의 전문을 망라한 체계적 문헌고찰은 아니다. 검색어·직접 링크·전문/초록 접근 여부·확인 못 한 수치는 각 상세 보고서에 남겼다. 서로 겹치는 메타분석의 참가자를 합산하거나, 효과크기를 이 앱의 향상률로 환산하지 않는다. 다음 원칙은 문헌과 사용자 요구를 연결한 **제품 설계 판단**이다.

핵심 판단의 근거를 압축하면 다음과 같다. `g`, `d`는 각 연구의 표준화 효과크기이며 퍼센트 향상률이 아니다. 표의 연구 수는 서로 독립인 전체 증거로 합산하지 않는다.

| 질문 | 확인한 주요 근거 | 결론을 좁히는 한계 |
| --- | --- | --- |
| AI 대화가 말하기 연습 수단이 될 수 있는가 | [Hou & Min, 2025 온라인/2026호](https://doi.org/10.1017/S0958344025100268): 말하기 관련 16개 연구·89효과, g=.61 | 검색 종료 2023-05, 현재 음성 모델 아님. 다수 소표본·시스템 혼합 |
| 한국인에게도 유망한가 | [Kang, 2025](https://doi.org/10.15738/kjell.25..202509.1299): 48명 ChatGPT-4o/또래 비교, 문법·어휘·과제 수행 이점 | 유창성·발음 차이는 유의하지 않음. 초록만 확인, 성인 자유 통화 전체로 일반화하지 않음 |
| 교정·자가수정 기회를 제공할 이유가 있는가 | [Sun et al., 2026](https://doi.org/10.1177/13621688261499464): 구두 문법 정확성 55개 연구·3,352명, g=.92 | 출판사 초록 확인. 효과의 시간 경과 감소, 정확성 향상이 전체 회화 능력과 같지는 않음 |
| 다음에 다시 꺼내 보는 복습이 필요한가 | [Kim & Webb, 2022](https://doi.org/10.1111/lang.12479): 48개 실험·3,411명, 분산 연습의 이점 | 정확한 1·3·7일 일정·자유대화 전이의 최적성을 제공하지 않음 |
| 반복을 많이 할수록 좋은가 | [Suzuki & Hanzawa, 2022](https://doi.org/10.1017/S0272263121000358): 79명, 몰아서 반복할 때 유창성 측면별 엇갈림 | 같은 이야기의 휴지 감소만으로 새 과제의 성공을 예측할 수 없음 |
| 한국어를 완전히 차단해야 하는가 | [Zhang & Brown, 2026](https://doi.org/10.1177/13621688261455050): 24개 연구·2,138명, 다언어 접근의 집단 간 d=.49 | 초록 확인. 교수법·대상이 다양하고 사용자가 선택한 영어 음성 정책 자체의 비교가 아님 |

## 1. 생각할 시간: 발언권을 보존하고, 잘못 끼어들면 회복한다

한국인 EFL 학습자 한 명이 ChatGPT-4와 3개월간 30회 역할극을 한 종단 연구에서 고정된 침묵 기준과 AI의 장황함이 상호작용의 제약으로 보고됐다. 한국인·AI 대화라는 직접성은 높지만 단일 사례라 발생률이나 해결책의 효과를 일반화할 수 없다. 별도의 30명 음성 대화 평가 연구에서도 3초 기준을 사용했는데 침묵 관련 끼어듦 문제가 관찰됐다. [Choi & Oh, 2026](https://doi.org/10.1016/j.system.2025.103959), [Karatay & Xu, 2025](https://doi.org/10.1002/tesq.70003).

**결정:** `무음이 일정 시간 발생했으니 답한다`에서 **발언 완료 여부·계속 말하려는 신호·사용자 제어·끼어듦 회복**을 함께 다루는 정책으로 발전시킨다.

- 문장 중 망설임, “Let me think”, “잠깐만”을 새 질문·격려·힌트로 덮지 않는다. 기다려 달라는 뜻은 입력 언어와 관계없이 존중한다.
- 자동 완료 판정은 의미·문맥을 활용하는 방식을 우선 검증한다. 기술 후보는 semantic VAD이며, 이 옵션 자체의 한국인 학습효과가 입증됐다고 표현하지 않는다.
- 사용자가 발언권을 직접 유지할 수 있는 수단을 별도로 설계한다. 이것은 잘못된 자동 판정을 복구하는 기능이다. 모든 통화를 버튼을 누르고 말하는 방식으로 강제하지 않는다.
- 사용자가 말을 다시 시작하거나 중지를 요구하면 AI 음성을 멈추고 이어 말하게 한다. 잘못 끊은 뒤 긴 사과나 새 질문으로 다시 발언권을 차지하지 않는다.
- 응답이 늦는 현상과 생각 중인 사람을 끊는 현상을 각각 측정한다. 둘 중 하나만 최소화하지 않는다.

**숫자 판단:** 기존 2초는 최적값이 아니다. 교실의 3초 wait-time, 자연 대화의 짧은 턴 사이 간격, API의 무음 기준은 서로 다른 측정이다. 새 기본값은 실제 모델의 적용 설정과 음성 행동을 확인해 정한다. 상세: [대화 속도·발언권 연구](dialogue-pacing-review.md).

## 2. 답변 길이: 필요한 의미를 전달하고 발언권을 돌려준다

상호작용 연구는 이해 가능한 입력과 사용자 산출·의미 확인이 함께 작동한다고 본다. 설명을 무조건 줄이거나 늘리는 처방은 나오지 않는다. 구어답게 반응하는 것과 단순한 단어 수 제한도 다르다. [Loewen & Sato, 2018](https://doi.org/10.1017/S0261444818000125).

**결정:** 매 턴 무엇을 해야 하는지에 따라 답변을 조절한다.

| 사용자 상황 | AI의 기본 행동 | 멈출 시점 |
| --- | --- | --- |
| 일상 이야기 | 내용에 맞는 짧은 반응 | 관련 반응이 끝났으면 멈춤. 질문은 필요한 경우만 |
| 사실·뜻 질문 | 직접 답과 이해에 필요한 정보 | 답이 충족되면 끝냄 |
| 이해 실패 | 더 쉬운 말 또는 짧은 예 | 사용자가 다시 반응할 공간을 남김 |
| 표현 도움 요청 | 사용할 수 있는 자연스러운 영어 표현 | 요청하지 않은 문법 강의·반복 과제 추가 안 함 |
| 상세 설명 요청 | 내용을 작은 단위로 나눠 설명 | 처음부터 긴 강의로 펼치지 않고 요청에 맞춰 확장 |
| 생각 중·도움 거절 | 기다림 또는 주제 유지 | 힌트·질문을 계속 추가하지 않음 |

`10~25단어, 최대 2문장`을 모든 상황의 절대 제한으로 사용하는 방향은 수정한다. 평상시에는 짧은 응답을 기본으로 하되, 뜻을 빠뜨리거나 사용자의 상세 요청을 무시하지 않는다. 고정 70:30 말하기 비율·최대 토큰으로 잘라내기를 학습 원칙으로 채택하지 않는다. 매 턴 질문은 최대 허용량과 별개로 의무가 아니다. 상세: [상호작용·산출 연구](learning-interaction-review.md), [기존 답변 길이 연구](voice-response-length.md), [비판적 검토](research-critical-appraisal.md).

## 3. 한국어 입력: 뜻을 이해하고 쉬운 영어로 연결한다

목표어 노출은 학습 기회를 제공하지만 이해 지원도 필요하다. 모국어를 교육적으로 활용한 연구는 영어 전용이 언제나 더 좋다는 주장을 뒷받침하지 않는다. 반대로 모국어 활용 연구가 이 서비스의 영어 음성 정책을 자동 한국어 답변으로 바꿔야 한다는 뜻도 아니다. [ACTFL 공식 지침](https://www.actfl.org/educator-resources/guiding-principles-for-language-learning/facilitate-target-language-use), [AI·모국어 활용 문헌 검토](ai-language-learning-review.md).

**결정:** 사용자가 요구한 **영어 음성 출력**은 유지한다. 한국어 입력은 실패나 문법 오류로 취급하지 않는다. 짧은 영어로 의미를 이어가며, 사후 한국어 설명은 별도로 유지한다.

- “야근해서 피곤해를 영어로?” → “You can say, ‘I’m tired because I worked late.’”
- “왜 worked야?” → “It happened in the past, so we use ‘worked.’”
- “너무 어려워” → 더 쉬운 영어로 재설명한다. 영어로만 말하라는 훈계로 끝내지 않는다.
- 혼합 발화의 뜻이 불확실하면 짧게 확인한다. 자연스럽게 들린다는 이유로 사용자의 의도를 새로 만들어내지 않는다.

위 예시는 정책 설명을 위해 작성했으며 실제 모델의 성공 사례가 아니다. 전사 언어 설정과 AI 출력 언어는 별개의 문제다. 영어 출력 정책을 위해 한국어 전사를 강제로 영어화하지 않는다. 전사 정확도 비교는 [기존 ASR 연구](voice-language-and-asr.md)에 따른다.

## 4. 교정 시점: 대화가 막힌 문제는 지금, 작은 오류는 구간 뒤

구두 교정은 학습에 도움이 된다는 축적된 근거가 있다. 다만 모든 문장을 즉시 교정하거나 모든 피드백을 종료 후로 미루는 단일 방침은 지지되지 않는다. 자기수정 기회·과제·측정 시점에 따라 결과가 달라진다. 상세 근거와 반례: [피드백·유지 연구](feedback-retention-review.md).

**결정:** 현재 통화의 목적을 유지하면서 교정 시점을 나눈다.

| 상황 | 방침 |
| --- | --- |
| 뜻을 이해하지 못했거나 잘못 이해할 위험 | 그 자리에서 짧게 확인 |
| 사용자가 표현·문법·발음을 질문 | 그 요청에 바로 답변 |
| 알아들을 수 있는 작은 문법·스타일 문제 | 발화 중간을 끊지 않고 자연스러운 구간 끝이나 통화 후로 이동 |
| 연습을 선택한 사용자 | 가능한 경우 스스로 수정할 기회 → 필요하면 모범 표현 → 선택적 재발화 |
| 전사가 의심스럽거나 의미가 불명확 | 확정 오류로 단정하지 않고 확인·보류 |

자기수정이 어려운 사용자에게 정답을 끝없이 숨기지 않는다. 대안 표현을 틀린 문장으로 표시하지 않으며, 오류 개수를 채우기 위한 교정을 만들지 않는다. 통화 내내 교정과 퀴즈를 의무화하지 않는다.

## 5. 통화 직후 기록: 즉시 접근과 능동적인 복습을 연결한다

**결정:** 통화를 종료하면 받은 대화문을 곧바로 열 수 있게 한다. 저장·전사 마무리·피드백 생성 때문에 접근을 막지 않는다. 수신된 내용, 기기 저장, 서버 저장, 전사 누락 상태는 구분한다. 이 부분은 명시된 사용자 요구와 기능 신뢰성만으로도 채택할 수 있다.

전사·자기 알아차림 연구에서 능동적으로 자기 발화를 검토하고 다시 표현하는 활동은 단순한 ASR 읽기와 다르다. 따라서 **대화문을 읽었다 = 학습했다**로 처리하지 않는다. 확인된 원문 옆에 교정의 근거와 선택 가능한 대안을 제공하고, 사용자가 고른 내용으로 다시 말해 볼 수 있게 연결한다. 원문 자동 전사와 교정문을 덮어쓰지 않는다. [전사 연구와 혼합된 결과](post-call-transcript.md), [산출·반복 연구](learning-interaction-review.md).

## 6. 복습: 다시 읽기에서 독립 회상·다른 상황 사용으로

반복 말하기와 분산 연습을 제공할 근거는 있다. 그러나 몰아서 반복하면 모든 유창성 지표가 좋아지는 것은 아니며, 같은 내용을 잘 말한 성과가 새 상황으로 자동 전이되지도 않는다. [Kim & Webb, 2022](https://doi.org/10.1111/lang.12479), [Suzuki & Hanzawa, 2022](https://doi.org/10.1017/S0272263121000358), [Rogers & Li, 2025](https://doi.org/10.1177/13621688251323047).

**결정:** 통화 내용을 모두 숙제로 바꾸지 않고, 사용자가 선택한 중요한 표현이나 의사소통 목표를 중심으로 복습한다.

1. 원문과 말하려던 뜻을 확인한다.
2. 필요한 교정·표현을 확인하고 원하면 자신의 말로 다시 말한다.
3. 나중에는 모범답을 먼저 보여 주지 않고 떠올려 보게 한다. 막히면 힌트·답 보기를 허용한다.
4. 익숙한 문장의 단순 반복 다음에는 다른 상황에서 그 뜻을 표현하게 한다.

`한 항목부터`, `한 번 더`는 부담을 줄이기 위한 시작안이다. 최적 개수라는 연구 결과가 아니다. 현재 1·3·7일 일정도 실용적인 초기 일정이며 개인별 최적 간격으로 표시하지 않는다. 열람·따라 말함·힌트 사용·독립 회상·새 상황 사용은 각각 다른 사실로 기록한다. 한 번의 성공으로 ‘숙달’을 확정하지 않는다. 상세: [피드백·유지 연구](feedback-retention-review.md).

## 7. 좋은 대화와 학습의 성공 기준

AI와의 만족도, 말한 양, 영어 점수는 서로 다른 결과다. 불안·동기와 성취의 상관은 인과 효과가 아니며, 빠르게 말하기와 실제 이해 가능성도 동일하지 않다. [동기·평가지표 상세](standards-outcomes-review.md).

**대화 품질:** 의도하지 않은 끼어듦, 완료 후 불필요한 대기, 의미에 맞는 답변, 이해 가능한 영어, 요청·거절 준수, 사용자 주도권, 전사·저장 신뢰성을 본다.

**학습의 관찰:** 답을 보기 전 회상, 다른 상황에서의 적절한 사용, 이해 실패를 스스로 복구했는지, 시간이 지난 뒤 유지되는지를 본다. 통화 시간·총 단어 수·출석·ASR 인식 성공·원어민 억양 모사를 실력 점수 하나로 합치지 않는다. 교정 정확도도 실제 발화와 원래 의도를 확인해야 한다.

AI는 반복 가능한 연습 상대와 복습 보조 역할로 채택한다. 이 제품이 사람과의 상호작용 전체를 대체하거나 AI 통화만으로 동일한 능력 향상을 보장한다고 주장하지 않는다.

## 현재 서비스와의 연결 및 구현 순서

아래는 **연구에 따른 설계 결론**이다. 문서가 있다는 이유로 해당 행동이 구현·배포됐다고 간주하지 않는다. 기존 배포 코드의 상태를 확인해 연결했다.

| 순서 | 현재 상태 | 다음 설계·구현 단위 | 확인할 것 |
| --- | --- | --- | --- |
| 1 | 즉시 대화문·저장 상태 분리 구현됨 | 접근·원문 보존을 유지하고 능동적 복습 연결 점검 | 종료 직후·누락·저장 실패·재접속 |
| 2 | 2초 server VAD | 발언권 보존·종료 판정·중지/회복을 담당하는 대화 제어 | 실제 음성에서 계속 말할 의도·진짜 완료 시점·겹침·불필요한 대기 |
| 3 | 10~25단어/최대 2문장 지침, 영어 출력 지침 | 기능별 답변 정책, 상세 요청 예외, 불필요한 질문 제거 | 의미 충족·영어 음성 준수·짧게/쉽게/자세히/그만 요청 |
| 4 | 원문 인용 교정·이의 제기·한국어 설명 존재 | 즉시 의미 확인과 사후 교정의 역할 구분, 선택적 재표현 연결 | 교정의 정확성·원뜻 보존·거절 가능성 |
| 5 | 선택 복습·1/3/7일·다음 통화 표현 기회 존재 | 회상 전 답 숨김·힌트 사용 구분·새 상황 사용 관찰의 일관성 점검 | 실제 기능을 먼저 확인한 뒤 필요한 부분만 보완. 이미 있는 기능을 새 구현으로 세지 않음 |

배포된 시각 디자인은 유지하는 제약으로 삼는다. 추가 발언권 제어처럼 새 조작이 필요한 항목은 기존 통화 구조에 맞는 최소 상호작용으로 별도 설계한다. `음소거`를 몰래 `생각 중` 의미로 바꾸지 않는다. 음성 원본 수집을 기능 배포에 묶어 자동 활성화하지 않는다.

세밀한 숫자와 실제 모델의 준수 여부는 구현 검증 항목이다. 여기서 검증할 것은 선택한 정책이 작동하는지이며, 매 기능에 장기 무작위 실험을 선행 조건으로 요구하는 것은 아니다. 반대로 소프트웨어 테스트·합성 음성·문헌만으로 실제 학습효과가 검증됐다고 보고하지 않는다.

## 결정하지 않는 주장

- 2초 또는 3초가 한국인 학습자에게 가장 좋다.
- 답변은 언제나 10~25단어·2문장 이하여야 한다.
- 영어 음성 정책 때문에 한국어 생각·질문·사후 설명도 금지해야 한다.
- AI와 오래 통화하거나 만족하면 그만큼 말하기 실력이 향상된다.
- 전사문은 실제 발화를 오류 없이 보존한다.
- 교정문을 읽거나 한 번 사용했으면 익혔다.
- 지금 조사한 논문이 현재 모델·현재 서비스의 성과를 직접 입증했다.
