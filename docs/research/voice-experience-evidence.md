# 통화 경험 개선: 연구 결론과 구현 판단

조사일: 2026-11-10 UTC / 2026-11-11 KST. 대상은 현재 배포된 `gpt-realtime-2.1-mini` 음성 통화와 `gpt-realtime-whisper` 전사다. 기존 배포 `c0edf056`의 대화문·응답 개선을 재검토했다. 이번 검토는 1차 연구·공식 명세를 중심으로 한 **주제별 문헌 검토**이며 체계적 문헌고찰이나 새로운 사용자 실험은 아니다.

## 먼저 정정하는 내용

기존 2초 무음, 10~25단어, 1~2문장, 전사 언어 자동 감지는 이 제품에서 효과가 입증된 최적값이 아니다. 특히 기존 512토큰 상한을 긴 답변의 원인으로 적은 것은 근거가 부족해 철회한다. 자동 검사의 통과는 화면·저장·요청 설정·회귀 검증이며 실제 모델의 응답 길이·언어 유지·끼어듦·전사 정확도를 입증하지 않는다.

기술 명세는 **설정이 지원되는지**, 연구는 **어떤 조건에서 무엇이 관찰됐는지**, 현장 평가는 **이 제품·사용자에게 도움이 되는지**를 각각 뒷받침한다. 소스 수를 합산해 충분성 점수를 만들지 않는다. 논문이 다른 모델·대상·과제를 다루거나 초록만 접근 가능하면 그 한계를 유지한다.

## 충분한 근거의 기준

1. **목표를 구분한다.** 직접 요청한 접근·언어 정책과 학습효과 주장은 다른 기준으로 판단한다. 재현된 화면·저장 오류는 요구·상태 모델·기능 검증으로 수정할 수 있다. 학습효과 연구가 없다고 명백한 기능 오류 수정을 막지는 않는다.
2. **실제 원인을 분리한다.** 요청한 설정과 공급자가 실제 적용한 설정, 모델 생성과 재생, 음성 이해와 비동기 전사, 전사문과 실제 발화를 구분한다. 실제 통화 음성·사건 대조 없이 사용자의 끼어듦 원인을 확정하지 않는다.
3. **변수 하나씩 비교한다.** 같은 입력·문맥·음성·속도·모델·전송 방식에서 선언한 처치만 변경한다. 모든 실패·취소·토큰 상한 종료·누락·재시도를 남기고 조건 순서를 섞는다. 실제 공급자 출력, TTS 입력, 사람의 녹음, 소프트웨어 모의 응답을 혼합하지 않는다.
4. **목표와 맞는 지표를 쓴다.** 짧은 답변 수나 질문 수만으로 좋은 대화를 판정하지 않는다. 뜻이 맞는지, 필요한 설명이 빠지지 않았는지, 사용자의 상세·짧게·조언 거부 요청을 지켰는지 함께 판단한다. 언어 판정은 문자 탐지와 구분하고, 턴 끝은 공급자 `speech_stopped`와 구분한다.
5. **판정 기준을 먼저 고정한다.** 의미 있는 개선폭·허용 지연·심각 오류 정의·불확실성/표본 중단 기준은 결과를 보기 전에 정한다. 현재 문헌에서 이 제품에 적용할 숫자가 나오지 않은 항목은 미정으로 남긴다. 임의로 높은 점수나 작은 표본을 통과 기준으로 만들지 않는다.
6. **사람과 기간이 필요한 주장은 기다린다.** 실제 한국인 영어 학습자의 이해·부담·발언권·선호를 측정하고, 학습 주장은 별도의 지연 회상·새 과제 전이로 확인한다. 현재 참여자·사람의 검토 자료는 없다는 기존 답변을 반영했다. 외부인에게 연락하거나 사용자 데이터를 새로 수집하지 않았다.

평가 구조는 [OpenAI Realtime 평가 안내](https://developers.openai.com/cookbook/examples/realtime_eval_guide)와 [평가 실무 지침](https://developers.openai.com/api/docs/guides/evaluation-best-practices)을 참고했다. 음성 입력 조건과 모델 행동을 나눠 진단하고, 자동 지표를 사람의 판단과 대조하는 방향을 적용한다. 이 문서의 제공자는 이 앱의 효과를 검증한 기관이 아니다. 중단 예정인 호스팅 Evals 플랫폼에 새 의존성을 추가하지 않는다.

## 이번에 설계·구현하는 범위

연구와 독립 검토가 뒷받침하는 범위는 **평가 조건을 고정하고 누락·실패·출처를 구분하는 오프라인 측정 도구**다. 답변·전사·턴 전환의 작성된 실험 사례를 준비하고, 나중에 수집한 실제 출력과 사람의 기준을 짝지어 계산한다. 이 도구는 모델을 호출하거나 학습자를 모사하지 않으며 서비스 설정을 자동 변경하지 않는다.

기존의 즉시 대화문 접근과 영어 정책은 유지한다. 고정 대기·길이·전사 언어를 다른 값으로 바꾸는 제품 구현과 재배포는 비교 근거가 확보될 때 진행한다. 이번 문헌 결과만으로 새 수치를 배포하지 않는다.

## 결과를 읽는 방법

- 빈 결과는 **미측정**이며 성공률 100%나 오류율 0%가 아니다.
- 작성된 시나리오의 수는 실제 참여자 수가 아니다. 공급자 응답이 없는 시나리오는 관찰 결과가 아니다.
- 파일에 기재된 실행 출처·모델·사람 검토는 제출자가 제공하거나 확인한 메타데이터다. 도구가 독립적으로 신원을 확인한 것으로 표현하지 않는다.
- 실제 출력과 사람 검토가 들어와도 해당 조건의 관찰일 뿐, 작은 벤치마크만으로 모든 사용자·장기 학습효과·배포 승인으로 확대하지 않는다.
