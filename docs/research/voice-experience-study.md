# 음성 경험 비교 설계와 측정 도구 사용법

상태: 연구용 설계·오프라인 도구. **실제 모델 비교·학습자 실험은 미실행이다.** 제품 정책의 근거 판단은 [연구 종합](voice-experience-evidence.md)에 기록했다. 현재 참여자·검토 자료·비교용 음성 및 판정 결과가 없다. 작성된 발화 예시는 녹음·관찰·사람의 정답을 대신하지 않는다.

## 세 실험을 분리한다

| 실험 | 고정하는 것 | 유일하게 바꾸는 것 | 판단할 내용 |
| --- | --- | --- | --- |
| `reply` | 같은 발화·문맥·출력 언어 정책·모델·음성·속도·VAD·생성 상한 | 일반적 간결화 대 과제별 간결화의 연구용 지침 | 의미를 보존하면서 필요한 설명·선택권을 지키는지. 단어 수 감소만으로 성공 판정하지 않음 |
| `asr` | 같은 실제 녹음·모델·지연·전송·분절·참조 원문 | 전사 언어 생략 대 영어 힌트 | 영어·한국어·혼합 발화 원문과 의미 보존. ASR이 학습자 문법을 몰래 고치는지도 검토 |
| `turntaking` | 같은 실제 녹음·문맥·답변 지침·모델·음성·속도 | 고정 무음 판정 대 선언된 의미 기반 판정 | 아직 말할 의도가 있는 쉼에서의 조기 응답과 실제 발화 종료 뒤의 기다림을 함께 비교 |

기본 제공 지침은 **연구용 프로토타입**이다. 현재 배포 전체 지침을 캡처한 것으로 표현하지 않는다. 실제 배포 비교에는 공급자가 적용한 전체 지침·문맥·모델·설정을 확보하고, 새 매니페스트와 버전·해시를 고정해야 한다. 인사·일반 답변·힌트·기억 갱신은 각각 경로를 기록한다. 이전 요청·역할·개인 기억을 임의로 빼서 같은 조건이라고 하지 않는다.

대화문 접근은 생성 모델 비교와 별개다. 기존 [브라우저 인수](../../test/end-transcript.browser.mjs)는 종료 직후 접근·늦은 전사·저장 상태·복구·재접속을 검사한다. 그 통과를 학습효과나 실제 모델 성능에 합산하지 않는다.

## 자료 수집 전에 고정할 사항

- 한국어 질문·뜻/표현 설명·한 단어 답변·재설명·상세 요청·조언 거부·인용된 지침 등 실제 사용과 관련된 사례를 포함한다. 시나리오의 필요한 의미와 허용 가능한 생략을 출력 생성 전에 정의한다.
- 음성은 사용이 허용된 자료만 쓴다. 사람의 자연 발화, TTS, 소프트웨어 모의 응답의 출처를 구분한다. 같은 대본을 다른 사람이 읽은 것은 같은 입력이 아니다. 동일 녹음의 SHA256과 출처를 매니페스트 입력에 고정한다.
- ASR 참조는 실제로 들린 말의 원문을 사람이 검토·합의한 자료로 준비한다. 정문으로 고친 문장·예정 대본·다른 ASR의 결과를 원문 정답으로 삼지 않는다. 불확실한 참조는 별도 표시한다.
- 턴 끝은 사람이 음성과 의도를 검토한 시각으로 기록한다. VAD의 `speech_stopped`는 비교 대상의 판단이며 정답 시각이 아니다. 타임라인의 0점과 단위를 두 조건에 동일하게 적용한다.
- 실행 순서·반복·실패 재시도·중단·제외·허용 지연/오류 우선순위·충분한 표본 정밀도 기준을 결과 생성 전에 기록한다. 기본 매니페스트의 반복 수는 도구 예시이며 연구로 입증된 충분한 표본 수가 아니다.
- 검토자는 조건 이름·단어 수를 보기 전에 의미 적합성·영어 정책·잘림을 판단하고, 가능하면 서로 독립적으로 검토한다. 이견은 삭제하거나 임의 평균으로 합의한 것처럼 바꾸지 않는다.

## 실행

네트워크·API 키·승인 계정 없이 오프라인으로 실행한다. 결과가 없을 때도 실행할 수 있으며 관찰 수 0과 미측정을 출력한다.

```sh
npm run eval:voice -- --study reply
npm run eval:voice -- --study asr
npm run eval:voice -- --study turntaking
```

실제 자료를 확보한 뒤에는 별도로 고정한 매니페스트, 관찰 출력, 사람 검토 파일을 제공한다. 자료는 저장소 밖 또는 무시되는 경로에 보관한다. 아래 경로는 형식 예시이며 이 파일들이 이미 수집됐다는 뜻이 아니다.

```sh
node scripts/evaluate-voice-experience.mjs \
  --manifest /private/voice-study/manifest.json \
  --study reply \
  --predictions /private/voice-study/predictions.json \
  --labels /private/voice-study/labels.json
```

입력 구조는 [작성된 시나리오](../../test/fixtures/voice-experience-benchmark.json), [검증기](../../scripts/evaluate-voice-experience.mjs), [도구 테스트](../../test/voice-experience-evaluation.test.mjs)에서 확인한다. JSON 원문을 수정하면 매니페스트·입력·설정·출력 해시를 다시 고정해야 한다. 전체 조건의 해시가 달라지면 기존 검토를 새 조건의 결과로 재사용하지 않는다.

도구의 `model_config`는 비교 조건을 기록하는 형식이며 공급자의 원본 설정 응답이나 실행 증명은 아니다. 실제 적용된 세션·응답 설정과 원본 사건·음성은 별도 보관하고 대응 관계를 검토한다. 실제 출력 음성에 대한 언어·잘림 검토는 해당 음성 해시와 청취 확인을 함께 기록한다.

## 측정값과 해석

- 답변의 영단어 수·한글 문자 존재는 진단값이다. 질문 부호와 실제 질문 부담, 한글 문자와 한국어 설명, 짧음과 적합성은 같지 않다. 사람이 의미·언어 정책·완결성을 별도로 판단한다.
- 완료·취소·토큰 상한 종료·전송 오류·결과 누락을 구분한다. 실패를 제외하고 성공한 응답만 모아 비교하지 않는다. 출처가 다른 쌍은 비교 가능한 쌍으로 세지 않는다.
- WER/CER는 NFC 정규화만 적용하고 대소문자·구두점·문법을 보존한다. 띄어쓰기 단위 WER와 공백 포함 코드포인트 CER의 분모를 명시한다. 이는 한국어 음절 CER·혼합 오류율·PIER의 대체 구현이 아니다. 참조가 비면 비율은 정의되지 않으며 허구의 0% 오류로 만들지 않는다.
- 사람의 실제 발화 종료 시각에 대한 응답 시각 차이는 검토자의 시각 판정에 따른 값이다. 검토 수는 고유 사용자 수나 턴 수가 아니다. 불확실한 시각·의도는 측정된 것처럼 채우지 않는다.
- 출처·실행 모델·참조 합의·사람 검토 표시는 제출자가 제공하거나 확인한 내용이다. 해시는 대응 관계를 검사하며, 실제 공급자 호출이나 사람의 신원을 인증하지 않는다. 수집 증거를 별도로 검토해야 한다.

이 도구에는 배포 승인 기능이 없다. 결과가 완벽하게 보이거나 짧아져도 학습효과·최적 기본값을 자동 선언하지 않는다. 실험 결과가 없는 현재 상태에서는 새 대기·길이·전사 기본값을 선정하지 않는다.

## 구현 검증 결과

새 평가 도구 검사16개와 전체 회귀 검사189개가 통과했다. 중복·다른 사례·오래된 입력/설정/출력/매니페스트·서로 다른 출처의 비교·음성 없는 공급자 주장·청취하지 않은 음성 판정·불확실한 시각·파일/계산량 한도를 검사한다. 이 검사의 모의 응답과 해시는 소프트웨어 시험용이며 실제 공급자 출력이 아니다.

실제 CLI의 빈 결과 확인:

| 실험 | 작성된 시나리오 | 관찰 출력 | 아직 없는 출력 셀 | 모델 성능·배포 판정 |
| --- | ---: | ---: | ---: | --- |
| `reply` | 12 | 0 | 72 | 미측정·판정 없음 |
| `asr` | 4 | 0 | 24 | 미측정·판정 없음 |
| `turntaking` | 4 | 0 | 24 | 미측정·판정 없음 |

출력 셀은 작성된 시나리오×두 조건×예시 반복3회의 계획 단위다. 20개 시나리오·120개 계획 셀은 실제 관찰이나 참여자 수가 아니다. 질문 부담·주관적 이해·발언권·장기 학습은 이 최소 도구로 자동 측정하지 않으며 별도의 사람 평가가 필요하다.
