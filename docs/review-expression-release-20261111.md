# 표현 한 건의 상세와 짧은 타입

사용자가 수정 시안 1번을 선택하고 타입을 간단하게 표시하도록 지시했다. [최종 시각 기준](design/review-learning-upgrade-20261111/selected-simple-types.png)에 맞춰 목록의 표현 한 건과 해당 상세를 연결한다.

## 사용자 경험

목록의 모든 표현에 짧은 타입 하나를 표시한다. 교정·대안·잘 쓴 표현은 해당 피드백 구분을 우선하고, 활용 제안에는 확인된 일상 구어·속어·구동사·관용어·패턴 등을 표시한다. 과거 자료에 학습 분류가 없으면 ‘표현’을 사용한다. 분류를 지어내거나 화면마다 분석을 생성하지 않는다.

상세에는 선택한 표현 한 건만 나타난다. 뜻, 실제 발화 또는 직접 질문, 짧은 쓰임, 필요한 격식 정보, 명시적으로 구분한 사용 예와 대안을 제공한다. 같은 통화의 다른 표현과 통화 전체 강점은 이어 붙이지 않는다. 새 탭이나 강제 퀴즈는 추가하지 않았다.

저장은 해당 표현의 기존 포인터를 사용하며 서버 확인 후 상태를 바꾼다. 응답을 잃으면 최신 상태부터 확인한다. 원문에서는 관련 발화를 표시하고 표현 상세와 목록의 읽던 위치·초점으로 돌아온다. 선택한 표현이 원문 변경·보류로 사라지면 다른 표현을 대신 보여주지 않는다. 이전 표현과 이전 로그인에서 늦게 도착한 응답을 차단한다.

## 새 분석과 기존 기록

새 회차 분석은 여섯 학습 영역과 표현 성격을 분리해 보관하고 필요한 쓰임·사용 예·대안을 함께 생성한다. 직접 질문은 실제 사용자 발화의 정확한 인용으로 연결한다. 잘 쓴 표현은 `strengths`의 실제 사용자 인용이 확인된 항목만 목록에 투영한다. AI가 다듬은 문장을 사용자가 잘 말한 것으로 표시하지 않는다. 같은 표현의 중복은 통화 안에서 합친다.

새 구조는 기존 분석의 항목 상한과 생성 예산을 유지한다. 중간 요약에는 추가 필드를 요구하지 않는다. 유형별 최소 개수와 생성 할당량은 없으며, 모든 항목은 출처와 현재 버전을 검사한다. 빈 결과도 허용한다. 오래된 노트는 추가 정보가 없는 상태로 읽고 일괄 재생성하지 않는다. 통화 후 서버 큐와 제한된 재시도 정책을 유지한다.

속어·일상 구어 등은 의미와 문맥을 설명하며, 검증하지 않은 빈도·유행·지역 주장을 생성하지 않도록 제한했다. 별도의 사용 빈도 자료 구축이나 실제 상대 발화 추출, 음성 기반 발음 학습은 이 구현에 포함하지 않는다. 기존 다음 통화 활용·연습·기억 경계도 유지한다.

## 검수

- 실제 PostgreSQL 호환 엔진에서 기존 기록, 새 학습 정보, 잘 쓴 표현의 정확한 인용, 보류·출처 변경·다른 계정, 저장과 권한을 검사했다.
- 실제 HTML/CSS·Chromium에서 표현 B만 표시, 모든 항목의 짧은 타입, 원문 복귀, 저장 확인, B의 지연 응답 후 A 유지, B 소멸 후 다른 항목 미표시, 계정·로그인 전환을 검사했다.
- 320px·200% 글자와 390px·1024px, 마지막 행동의 하단 메뉴 가림, 브라우저 오류를 검사했다. [디자인 검수](../design-qa.md)에 원본·구현의 실제 비교를 남겼다.
- 기존 로그인·통화·분석·복습·복원 브라우저 회귀 검사, 타입 검사, 기억·학습 평가와 구성된 운영 빌드를 확인했다.

화면과 대화 입력은 합성 자료다. 실제 승인 사용자의 운영 통화나 학습효과 검증으로 보고하지 않는다.
