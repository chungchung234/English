# 날짜별 복습과 통화별 학습 노트

사용자가 선택한 수정 3안에 맞춰 표현마다 독립적인 경계를 두고, 날짜에는 ‘어제’ 등 상대 날짜를 함께 표시하지 않는다. [최종 시각 기준](research/review-boundaries-20261111/images/04-selected-final.png)과 [디자인 검수](../design-qa.md)를 기준으로 한다.

## 사용 흐름

복습 → 날짜별 통화와 표현 목록 → 선택한 표현 위치의 통화 학습 노트 → 필요한 발화의 원문 → 읽던 위치로 복귀한다. 표현 하나만 별도 페이지에 고립시키지 않는다. 저장한 표현은 별도 탭에서 다시 찾는다.

목록은 본인 계정의 Alex·Mia·Juno 자료를 통화 날짜·상대·시각으로 정리한다. 날짜는 분석 생성일이 아닌 통화 시작 시각과 저장된 통화 시간대를 기준으로 한다. 과거 시간대가 없는 기록은 현재 표시 시간대를 사용한다는 표시를 유지한다. 같은 날짜의 여러 통화는 따로 구분하며, 오래된 기록도 날짜 이동과 페이지 조회로 접근할 수 있다.

한 페이지의 통화 수는 12개로 제한하지만, 표현을 추천 경로의 처음 1~3개로 자르지 않는다. 분석에 담긴 유효한 교정·대안·활용 표현을 읽으며, 같은 통화의 중복 표현은 합친다. 각 타입은 0개 또는 여러 개일 수 있다. 기존 모델 출력 상한은 자원 제한으로 유지하며 타입별 최소 개수나 채우기 목표를 두지 않는다.

기본 목록에는 ‘교정/대안’ 표식을 짧게 표시하고 ‘다시 쓸 표현’ 반복 라벨은 생략한다. 상세에는 원래 발화, 교정인지 대안인지, 뜻·짧은 이유, 출처와 저장 행동을 제공한다. 잘한 점은 해당 통화의 별도 피드백이다. 새 분석에는 짧은 한국어 뜻·쓰임을 포함한다. 과거 노트에 뜻이 없으면 없는 상태로 읽고, 화면 방문마다 AI를 호출하거나 원문을 바꾸지 않는다. 중간 요약에는 이 추가 번역 필드를 요구하지 않는다.

통화 직후의 원문·저장 확인 흐름은 유지한다. 기존 주간 분석은 ‘최근 통화’에서 접근해 날짜별 복습 목록에 별도 큰 버튼을 추가하지 않는다. 과거 연습 등록·회상·제외·의도 재검토와 데이터 호환은 유지하되 기본 목록의 중첩 펼침으로 되돌리지 않는다.

## 데이터와 상태

`review_journal`은 계정 내 여러 상대의 통화를 안정적인 시작 시각+ID 커서로 조회한다. `review_note`는 해당 통화의 최신 전체 분석과 실제 전사의 버전, 발화 출처, 제외·보류 상태를 다시 확인한다. 무효화된 예전 결과를 최신 교정처럼 공개하지 않는다. 준비 중·부분 기록·정리할 내용 없음·불러오기 실패를 구분한다. 분석 실패 재처리는 기존 서버 작업 큐 정책을 그대로 사용한다.

`review_bookmarks`는 회차와 표현 키, 저장 여부와 revision만 보관한다. 원문을 다시 복사하지 않는다. 책갈피는 연습 등록·숙달·캐릭터 기억과 별개다. 일반 사용자는 자기 행만 조회하고 수정은 출처를 검사하는 RPC로만 수행한다. 두 기기의 오래된 저장 의도는 revision 비교로 충돌 처리하며, 결과를 모르는 전송은 상태 조회로 확인한다. 로그아웃·다른 계정·같은 계정의 새 로그인 이후 도착한 응답은 이전 화면을 되살리지 못한다.

새 책갈피는 기존 전체 기록 내보내기에 포함한다. 복원은 계정이 소유한 회차의 저장 포인터만 되살린다. 문장·출처 증거·연습 이력을 만들거나 이후의 저장 해제 선택을 덮어쓰지 않는다. 원문이 바뀌어 유효한 표현이 없으면 기존 저장 포인터를 근거로 새 표현을 지어내지 않는다.

학습 자료를 여러 상대에서 모아 보는 것은 사용자 자신의 탐색 기능이다. AI 통화에 다른 캐릭터의 기억을 섞는 변경은 없다. 새 날짜별 조회·저장·원문 이동에는 AI 생성 요청이 발생하지 않는다.

## 검증 기록

실제 PostgreSQL 호환 엔진에서 타입별 3/0/2개와 빈 분석, 처음 3개 이후 표현, 같은 문장 중복, 서로 다른 상대, 33개 통화·같은 시각의 커서, 자정과 시간대, 저장 CAS, 백업 포인터, 전사 변경·보류·다른 계정·승인 철회를 검사했다.

실제 HTML/CSS와 Chromium에서 표현 선택 → 통화 노트 → 출처 → 복귀, 저장 확인·불확실한 응답, 저장한 표현 탭, 날짜·이전 페이지, 계정/로그인 전환, 320px·200% 글자·1024px을 검사했다. 합성 인증·대화·모델 입력으로 실제 운영 학습 효과를 검증한 것은 아니다. 상세 화면과 시안 대조 증거는 위 디자인 검수에 남겼다.
