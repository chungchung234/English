# 소셜 로그인 설정

Supabase Authentication의 Google·Kakao 제공자 설정에 해당 서비스의 클라이언트 ID와 Secret을 입력합니다. 키 값은 문서에 기록하지 않습니다.

각 개발자 콘솔에 등록할 리디렉션 주소는 해당 Supabase 프로젝트의 `https://<project-ref>.supabase.co/auth/v1/callback`입니다. Supabase의 Site URL과 허용 리디렉션에는 실제 홈페이지 주소를 등록합니다.

카카오는 이메일 동의 항목을 설정하고, 승인 목록의 이메일로 로그인해야 합니다. 기존 계정에 로그인한 상태의 계정 연결 기능을 사용하면 동일한 사용자로 연결할 수 있습니다.

홈페이지는 서버의 제공자 설정을 읽어 사용 가능한 로그인 버튼만 활성화합니다. 제공자 페이지 도달, 동의 완료, 앱 복귀, 승인 계정 접근까지 각각 확인해야 최종 로그인 검증이 완료됩니다.
